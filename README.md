# 고리 (aboutmeat.co.kr)

**축산업에 필요한 모든 연결, 고리** — 원육 구매부터 가공·OEM, 물류, 인력, 당일알바,
구인구직, 장비·부자재, 창업·인테리어, HACCP·컨설팅까지 축산업에 필요한 업체와 사람을
연결하는 요청·견적 매칭 플랫폼입니다.

## 핵심 흐름

```
요청 등록 → 조건 매칭(업체 알림) → 견적 도착 → 비교 → 채팅 → 선택
        → 거래 진행(거래확정·준비중·배송중·완료) → 후기·평점
```

## 주요 기능

| 영역 | 내용 |
|---|---|
| 요청 등록 | 3단계 마법사, 8대분류별 입력 항목 분기, 구조화 저장(jsonb) |
| 매칭 | 요청 등록 시 관심 분야·지역이 맞는 업체에 자동 알림 (DB 트리거) |
| 바로견적 | 등록 직후 조건이 맞는 업체를 즉시 추천 |
| 견적 비교 | 가격·시세대비·인증·지역·납기·평점·거래실적·응답률 비교, 5가지 정렬 |
| 구조화 견적 | 단가 × 수량 = 총액 자동 계산, 시세 대비 % 표시 |
| 채팅 | 요청자 ↔ 업체 1:1 (읽음 표시, 알림 연동) |
| 인증 | 사업자등록(체크섬 검증) · 축산물 영업허가 · HACCP |
| 당일알바 | 구인구직과 분리, 지원자를 경력·평점·작업횟수로 선택 |
| 거래관리 | 12개 탭 — 요청/견적/채팅/거래/당일알바/관심업체/후기/알림/정보 |

### 시세 데이터 입력

`market_prices` 테이블에 행을 넣으면 견적 카드에 **시세 대비 ±%** 가 자동으로 표시됩니다.

```sql
insert into market_prices (category, item, grade, price, unit, price_date)
values ('beef', '한우 등심', '1+', 64000, '원/kg', current_date);
```

## 디자인 시스템

`index.html` 의 `:root` 에 브랜드 토큰이 정의돼 있습니다. 기존 변수명(`--gn` 등)을
유지하고 값만 매핑해 두어, 토큰 하나를 바꾸면 전 사이트에 반영됩니다.

**잉크 차콜 베이스 · 크림슨 브랜드 · 앰버 보조**

| 토큰 | 값 | 용도 |
|---|---|---|
| `--gori-ink-900` | `#12161B` | 히어로·다크 표면 (흰 글씨 대비 18.2:1) |
| `--gori-crimson` (`--gn`) | `#D91F3A` | 브랜드·CTA (흰 배경 4.99:1) |
| `--gn-on-tint` | `#A8142A` | 크림슨 틴트 배경 위 글씨 (6.58:1) |
| `--gori-amber` (`--amber`) | `#F5A524` | 급구·별점·강조 (잉크 위 8.9:1) |
| `--up` / `--dn` | `#CC2F35` / `#2F6FE0` | 시세 상승 / 하락 |
| `--ink` / `--ink3` / `--ink4` | `#14181C` / `#6E7480` / `#71767F` | 본문 / 보조 / 3차 |

**역할 분리**: 크림슨은 브랜드·CTA, 앰버는 급구·별점·시세 강조. 둘을 섞지 않습니다.
카테고리 8개는 각각 고유 틴트(`.ct-meat` ~ `.ct-haccp`)를 가집니다.

폰트 Pretendard(jsDelivr) → Noto Sans KR 폴백. 히어로 31px / 섹션 19px / 숫자 21px.
라운드 카드 16~18px, 아이콘박스 18px. 그림자는 검색바·FAB 에만.

모든 텍스트 조합 WCAG AA(4.5:1) 이상, 모바일 터치 타깃 44px 이상으로 검증돼 있습니다.

## 홈 화면에 추가 (PWA)

모바일에서 고리를 앱처럼 홈 화면에 둘 수 있습니다. 카카오 알림이 없는 동안
사용자가 다시 들어오게 만드는 통로입니다.

- 안드로이드·크롬: 홈 화면 하단에 "홈 화면에 추가" 안내가 뜹니다. 닫으면 30일간 안 뜹니다.
- 아이폰·사파리: `공유 → 홈 화면에 추가` 안내를 보여줍니다.
- 앱 아이콘을 길게 누르면 **요청 올리기 / 업체 찾기 / 당일알바 / 거래관리** 바로가기가 나옵니다.

`sw.js`(서비스 워커)는 **항상 네트워크를 먼저** 씁니다. 새로 배포한 파일이
캐시에 막혀 안 보이는 일은 생기지 않고, 네트워크가 끊겼을 때만 캐시를 씁니다.
문제가 생기면 브라우저 콘솔에서 `gSWOff()` 를 실행하면 서비스 워커와 캐시가
모두 해제됩니다.

## 최초 1회 설정

견적 비교 · 당일알바 · 후기 · 알림 · 관심업체 기능은 신규 테이블이 필요합니다.

1. Supabase 대시보드 → **SQL Editor**
2. `db/phase2_schema.sql` 내용을 붙여넣고 **Run**
3. 이어서 `db/phase3_schema.sql` 도 **Run** (채팅·매칭 알림·인증·거래·시세)
4. `db/phase4_admin.sql` **Run** — 그 안의 **3번 블록**에서 본인 이메일을
   관리자로 등록하세요. 등록해야 `admin.html` 에 로그인할 수 있습니다.
5. `db/phase5_storage.sql` **Run** — 업체 사진 저장소.
   SQL 이 막히면 대시보드에서 만들어도 됩니다:
   Storage → New bucket → 이름 `supplier-photos` → **Public bucket** 체크
6. (선택) `db/phase6_realtime.sql` **Run** — 새 견적·새 메시지·새 알림이
   화면을 다시 열지 않아도 바로 나타납니다. 테이블·데이터는 건드리지 않고
   기존 테이블 3개를 실시간 발행 목록에 추가만 합니다. 실행하지 않아도
   지금까지처럼(폴링·수동 새로고침) 동작합니다.

### 사업자 정보 채우기 (서비스 공개 전 필수)

`site-info.js` 를 열어 값을 채워주세요. 비어 있으면 푸터와 약관·방침 화면에
주황색 **(미기재)** 로 표시됩니다.

```js
window.GORI_BIZ = {
  company:      "고리",              // 상호
  ceo:          "홍길동",            // 대표자
  brn:          "000-00-00000",     // 사업자등록번호
  mailOrder:    "제0000-서울강남-0000호",  // 통신판매업 신고번호
  address:      "서울시 ...",
  phone:        "02-000-0000",
  email:        "help@aboutmeat.co.kr",
  privacyOfficer:"대표 홍길동",       // 개인정보 보호책임자
  hostRegion:   "싱가포르",           // Supabase 프로젝트 리전
  effective:    "2026-09-05"
};
```

왜 필요한가

- **상호·대표자·주소·전화·이메일·사업자등록번호·통신판매업 신고번호**는
  전자상거래법 제10조에 따라 사이트에 표시해야 합니다.
- **개인정보 보호책임자**는 개인정보 보호법 제31조에 따라 지정·공개해야 합니다.
- **hostRegion** 은 Supabase 프로젝트가 있는 리전입니다 (대시보드 → Settings →
  General → Region). 개인정보 국외 이전 고지에 들어갑니다.

확인되지 않은 번호는 적지 마세요. 잘못 적는 것 자체가 표시 의무 위반입니다.

`terms.html`(이용약관)과 `privacy.html`(개인정보처리방침)은 이 코드가 실제로
수집·제공하는 항목에 맞춰 작성해 두었습니다. 서비스 내용이 바뀌면 두 문서의
해당 표도 같이 고쳐주세요. 공개 전에 한 번은 직접 읽어보시길 권합니다.

### 업체 온보딩 (`업체 등록`)

4단계 마법사로 통합돼 있습니다. 이전에는 등록·인증·관심분야·바로견적이 네 화면에
흩어져 있었습니다.

| 단계 | 내용 |
|---|---|
| 1 기본 정보 | 업체명·대표자·연락처·영업 지역·주소 |
| 2 취급 분야 | 8대분류 다중 선택 → **여기서 고른 분야의 요청 알림을 받습니다** · 품목·서비스·최소량·납기 |
| 3 인증 서류 | 사업자등록(체크섬 검증)·축산물 영업허가·HACCP → **입력하면 인증 심사가 자동 접수됩니다** |
| 4 사진·알림 | 사진 최대 6장(업로드 전 1600px·JPEG 82%로 자동 축소) · 소개 · 바로견적 참여 |

등록을 마치면 `suppliers` 저장 + `verifications` 자동 신청 + `supplier_prefs` 알림 설정이
한 번에 처리됩니다. 저장소 버킷이 없으면 사진만 건너뛰고 나머지는 정상 등록됩니다.

### 관리자 콘솔 (`/admin.html`)

Supabase Auth 로그인 + `admins` 표 대조로 접근을 통제합니다.
프론트엔드 비밀번호가 아니라 실제 계정 인증입니다.

| 탭 | 기능 |
|---|---|
| 대시보드 | 요청·견적·거래·업체 현황, 인증 대기·시세 미입력 알림 |
| 인증 심사 | 사업자·HACCP·축산물허가 승인/반려 → 업체 배지 자동 반영 |
| 업체 | 목록·수동 인증·삭제 |
| 요청 / 견적 / 거래 | 조회, 거래 상태 변경 |
| 당일알바 / 후기 | 조회·삭제 |
| 시세 | **입력·수정·삭제** — 여기 입력한 값이 홈 상단과 견적 「시세 대비 %」에 사용됩니다 |

스크립트는 **추가 전용**입니다. `DROP` / `DELETE` / `TRUNCATE` 가 없고, 기존 컬럼을
변경하지 않으며, 여러 번 실행해도 안전합니다.

실행 전에도 사이트는 정상 동작합니다. 신규 테이블이 필요한 화면에는 안내 문구가 뜨고,
요청 등록은 기존 컬럼만으로 자동 저장됩니다.

## ⚠️ 보안 점검 필요

`suppliers.html` · `jobs.html` · `purchase_request.html` 은 브라우저에 노출되는 anon 키로
`UPDATE` · `DELETE` 를 실행합니다. 해당 테이블에 RLS 정책이 없다면 URL 을 아는 누구나
데이터를 삭제할 수 있습니다. `db/phase2_schema.sql` 하단의 **4. 보안 강화** 항목을
확인하고, 관리자 인증을 붙인 뒤 RLS 를 적용하세요.
