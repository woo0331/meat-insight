# 고리 (aboutmeat.co.kr)

**축산업에 필요한 모든 연결, 고리** — 원육 구매부터 가공·OEM, 물류, 인력, 당일알바,
구인구직, 장비·부자재, 창업·인테리어, HACCP·컨설팅까지 축산업에 필요한 업체와 사람을
연결하는 요청·견적 매칭 플랫폼입니다.

## 핵심 흐름

```
요청 등록 → 조건 매칭(업체 알림) → 견적 도착 → 비교 → 채팅 → 선택
        → 거래 진행(거래확정·준비중·배송중·완료) → 후기·평점
```

## 주요 기능

| 영역 | 내용 |
|---|---|
| 요청 등록 | 3단계 마법사, 8대분류별 입력 항목 분기, 구조화 저장(jsonb) |
| 매칭 | 요청 등록 시 관심 분야·지역이 맞는 업체에 자동 알림 (DB 트리거) |
| 바로견적 | 등록 직후 조건이 맞는 업체를 즉시 추천 |
| 견적 비교 | 가격·시세대비·인증·지역·납기·평점·거래실적·응답률 비교, 5가지 정렬 |
| 구조화 견적 | 단가 × 수량 = 총액 자동 계산, 시세 대비 % 표시 |
| 채팅 | 요청자 ↔ 업체 1:1 (읽음 표시, 알림 연동) |
| 인증 | 사업자등록(체크섬 검증) · 축산물 영업허가 · HACCP |
| 당일알바 | 구인구직과 분리, 지원자를 경력·평점·작업횟수로 선택 |
| 거래관리 | 12개 탭 — 요청/견적/채팅/거래/당일알바/관심업체/후기/알림/정보 |

### 시세 데이터 입력

`market_prices` 테이블에 행을 넣으면 견적 카드에 **시세 대비 ±%** 가 자동으로 표시됩니다.

```sql
insert into market_prices (category, item, grade, price, unit, price_date)
values ('beef', '한우 등심', '1+', 64000, '원/kg', current_date);
```

## gori-app.js 고치는 법

`gori-app.js`(30만 자)는 **직접 고치지 마세요.** `src/` 의 조각 파일들을 고치고
빌드하면 됩니다.

```bash
node build.js           # src/ → gori-app.js
node build.js --check   # 빌드 결과가 현재 파일과 같은지 확인
```

조각은 기능 단위로 나뉘어 있습니다.

| 파일 | 내용 |
|---|---|
| `01_core` ~ `06_my` | 공통·요청·견적·당일알바·업체·거래관리 |
| `08_match` ~ `11_wire3` | 매칭 알림·채팅·인증·거래 관리 |
| `13_onboard` · `12_redesign` | 업체 온보딩 · 디자인 개편 |
| `14_router` | URL 라우팅 (뒤로가기·링크 공유) |
| `15_filter` | 목록 검색·정렬 |
| `16_edit` | 요청 수정·삭제, 견적 철회 |
| `17_market` | 시세 (market_prices 연동) |
| `18_jobs` | 구인구직 (두 출처 통합) |
| `19_find` | 비로그인 요청 조회 |
| `20_live` | 실시간 갱신 (Realtime) |
| `21_guard` | 거래 무결성 (마감·중복·권한·번호 검증) |
| `22_pwa` | 홈 화면에 추가 |
| `23_notif` | 알림 전체 읽음·하단 네비 뱃지 |
| `24_content` | 홈 콘텐츠 (GORI_CONTENT) |
| `25_a11y` | 접근성 |
| `26_kakao` | 카카오 로그인 |
| `27_offline` | 연결 실패 처리 |
| `28_stale` | 오래된 요청 |
| `07_init` | **초기화 — 반드시 마지막** (IIFE 닫는 괄호가 여기 있습니다) |

**순서가 중요합니다.** 기존 함수를 지우지 않고 바깥에서 감싸는 방식이라, 나중에
붙는 조각이 앞의 것을 감쌉니다. `07_init.js` 는 항상 마지막이고, 확장 조각들은
`12_redesign` 뒤에 와야 리디자인이 덮어쓰지 않습니다. `build.js` 의 `ORDER` 가
정답이며, `src/` 에 파일을 추가하고 `ORDER` 에 안 넣으면 빌드가 막습니다.

`index.html` 과 `meat_insight_main.html` 은 같은 내용이어야 합니다. `index.html`
을 고쳤으면 `cp index.html meat_insight_main.html` 을 잊지 마세요.

## 디자인 시스템

`index.html` 의 `:root` 에 브랜드 토큰이 정의돼 있습니다. 기존 변수명(`--gn` 등)을
유지하고 값만 매핑해 두어, 토큰 하나를 바꾸면 전 사이트에 반영됩니다.

**잉크 차콜 베이스 · 크림슨 브랜드 · 앰버 보조**

| 토큰 | 값 | 용도 |
|---|---|---|
| `--gori-ink-900` | `#12161B` | 히어로·다크 표면 (흰 글씨 대비 18.2:1) |
| `--gori-crimson` (`--gn`) | `#D91F3A` | 브랜드·CTA (흰 배경 4.99:1) |
| `--gn-on-tint` | `#A8142A` | 크림슨 틴트 배경 위 글씨 (6.58:1) |
| `--gori-amber` (`--amber`) | `#F5A524` | 급구·별점·강조 (잉크 위 8.9:1) |
| `--up` / `--dn` | `#CC2F35` / `#2F6FE0` | 시세 상승 / 하락 |
| `--ink` / `--ink3` / `--ink4` | `#14181C` / `#6E7480` / `#71767F` | 본문 / 보조 / 3차 |

**역할 분리**: 크림슨은 브랜드·CTA, 앰버는 급구·별점·시세 강조. 둘을 섞지 않습니다.
카테고리 8개는 각각 고유 틴트(`.ct-meat` ~ `.ct-haccp`)를 가집니다.

폰트 Pretendard(jsDelivr) → Noto Sans KR 폴백. 히어로 31px / 섹션 19px / 숫자 21px.
라운드 카드 16~18px, 아이콘박스 18px. 그림자는 검색바·FAB 에만.

모든 텍스트 조합 WCAG AA(4.5:1) 이상, 모바일 터치 타깃 44px 이상으로 검증돼 있습니다.

## 홈 화면에 추가 (PWA)

모바일에서 고리를 앱처럼 홈 화면에 둘 수 있습니다. 카카오 알림이 없는 동안
사용자가 다시 들어오게 만드는 통로입니다.

- 안드로이드·크롬: 홈 화면 하단에 "홈 화면에 추가" 안내가 뜹니다. 닫으면 30일간 안 뜹니다.
- 아이폰·사파리: `공유 → 홈 화면에 추가` 안내를 보여줍니다.
- 앱 아이콘을 길게 누르면 **요청 올리기 / 업체 찾기 / 당일알바 / 거래관리** 바로가기가 나옵니다.

`sw.js`(서비스 워커)는 **항상 네트워크를 먼저** 씁니다. 새로 배포한 파일이
캐시에 막혀 안 보이는 일은 생기지 않고, 네트워크가 끊겼을 때만 캐시를 씁니다.
문제가 생기면 브라우저 콘솔에서 `gSWOff()` 를 실행하면 서비스 워커와 캐시가
모두 해제됩니다.

## 최초 1회 설정

견적 비교 · 당일알바 · 후기 · 알림 · 관심업체 기능은 신규 테이블이 필요합니다.

1. Supabase 대시보드 → **SQL Editor**
2. `db/phase2_schema.sql` 내용을 붙여넣고 **Run**
3. 이어서 `db/phase3_schema.sql` 도 **Run** (채팅·매칭 알림·인증·거래·시세)
4. `db/phase4_admin.sql` **Run** — 그 안의 **3번 블록**에서 본인 이메일을
   관리자로 등록하세요. 등록해야 `admin.html` 에 로그인할 수 있습니다.
5. `db/phase5_storage.sql` **Run** — 업체 사진 저장소.
   SQL 이 막히면 대시보드에서 만들어도 됩니다:
   Storage → New bucket → 이름 `supplier-photos` → **Public bucket** 체크
6. (선택) `db/phase6_realtime.sql` **Run** — 새 견적·새 메시지·새 알림이
   화면을 다시 열지 않아도 바로 나타납니다. 테이블·데이터는 건드리지 않고
   기존 테이블 3개를 실시간 발행 목록에 추가만 합니다. 실행하지 않아도
   지금까지처럼(폴링·수동 새로고침) 동작합니다.

### 사업자 정보 채우기 (서비스 공개 전 필수)

`site-info.js` 를 열어 값을 채워주세요. 비어 있으면 푸터와 약관·방침 화면에
주황색 **(미기재)** 로 표시됩니다.

```js
window.GORI_BIZ = {
  company:      "고리",              // 상호
  ceo:          "홍길동",            // 대표자
  brn:          "000-00-00000",     // 사업자등록번호
  mailOrder:    "제0000-서울강남-0000호",  // 통신판매업 신고번호
  address:      "서울시 ...",
  phone:        "02-000-0000",
  email:        "help@aboutmeat.co.kr",
  privacyOfficer:"대표 홍길동",       // 개인정보 보호책임자
  hostRegion:   "싱가포르",           // Supabase 프로젝트 리전
  effective:    "2026-09-05"
};
```

왜 필요한가

- **상호·대표자·주소·전화·이메일·사업자등록번호·통신판매업 신고번호**는
  전자상거래법 제10조에 따라 사이트에 표시해야 합니다.
- **개인정보 보호책임자**는 개인정보 보호법 제31조에 따라 지정·공개해야 합니다.
- **hostRegion** 은 Supabase 프로젝트가 있는 리전입니다 (대시보드 → Settings →
  General → Region). 개인정보 국외 이전 고지에 들어갑니다.

확인되지 않은 번호는 적지 마세요. 잘못 적는 것 자체가 표시 의무 위반입니다.

`terms.html`(이용약관)과 `privacy.html`(개인정보처리방침)은 이 코드가 실제로
수집·제공하는 항목에 맞춰 작성해 두었습니다. 서비스 내용이 바뀌면 두 문서의
해당 표도 같이 고쳐주세요. 공개 전에 한 번은 직접 읽어보시길 권합니다.

### 홈 콘텐츠 채우기 (`site-info.js` → `GORI_CONTENT`)

홈의 **축산 뉴스 · 창업 인사이트 · 실시간 매물 · 커뮤니티 인기글** 칸은
`site-info.js` 의 `GORI_CONTENT` 에 넣은 것만 표시됩니다. 비워두면 각 칸에
"준비 중" 안내가 나오고, **네 칸이 모두 비면 "고리 소식·정보" 섹션 전체가
접힙니다.** 내용을 하나라도 넣으면 자동으로 다시 펼쳐집니다.

```js
window.GORI_CONTENT = {
  news: [
    { title:"한우 도매가 3주 연속 상승", url:"https://...", date:"2026-09-01", source:"농민신문" }
  ],
  insights: [
    { title:"소규모 육가공 공장 창업 체크리스트", url:"/meat_insight_cases.html", date:"2026-09-01" }
  ],
  props: [ { name:"한돈 지육 500kg", info:"경기 안성 · 직접 문의", url:"" } ],
  community: [ { title:"발골 인력 구할 때 팁", url:"...", count:3 } ]
};
```

**왜 비웠는가** — 원래 이 칸들에는 예시 데이터가 들어 있었는데, 실제 정보처럼
읽혔습니다. 특히 축산 뉴스에 `"ASF 방역 강화…전국 일제 점검"`,
`"농식품부, 축산 수급 안정 대책 발표"`, `"수입육 관세 인하 검토"` 처럼 실제
기관과 정책을 지목한 가짜 헤드라인이 있었습니다. 방역 관련 허위정보는 특히
위험해서 전부 비웠습니다. **확인된 내용만 넣어주세요.**

### 만들지 않은 기능 스위치 (`GORI_FEATURES`)

```js
window.GORI_FEATURES = { pay: false };
```

`pay` 는 **고리페이(거래대금 안심결제)** 배너입니다. 결제 코드가 한 줄도 없는데
홈 상단에 광고되고 있어서 껐습니다. 에스크로·안심결제는 **전자금융거래법** 대상이라
실제로 등록하고 구축한 뒤에만 `true` 로 바꾸세요. 배너 마크업은 그대로 남아 있어
스위치만 켜면 됩니다.

### 카카오 로그인 켜기

코드는 다 들어가 있습니다. **사이트에 카카오 키를 넣을 필요는 없습니다** —
Supabase 가 중간에서 처리하므로 키는 Supabase 대시보드에만 넣습니다.

1. [카카오 개발자센터](https://developers.kakao.com) 에서 앱 생성 →
   **REST API 키**와 **Client Secret** 발급
2. 카카오 앱 → 카카오 로그인 → **Redirect URI** 에 아래를 등록
   ```
   https://igignylgzjphtnyxhhsd.supabase.co/auth/v1/callback
   ```
3. 카카오 앱 → 동의항목에서 **닉네임**(과 필요하면 이메일)을 필수/선택으로 설정
4. Supabase → **Authentication → Providers → Kakao** 를 켜고 위 키 2개 입력
5. Supabase → **Authentication → URL Configuration → Site URL** 에
   `https://aboutmeat.co.kr` 입력

설정 전에 버튼을 누르면 "카카오 로그인이 아직 켜져 있지 않습니다. 이메일로
로그인해주세요." 라고 안내합니다. (예전처럼 "준비 중" 만 뜨지 않습니다.)
로그인 후에는 보고 있던 화면으로 돌아오고, 카카오 닉네임을 이름으로 채웁니다.

### 오래된 요청

요청은 등록되면 계속 "견적대기" 로 남습니다. 구매자가 오프라인에서 이미
해결했어도 목록에 남아, 업체가 몇 달 전 요청에 견적을 보내고 연락이 안 되는
일이 생깁니다. **자동으로 지우거나 상태를 바꾸지는 않습니다**(구매자 데이터입니다).

- **30일** 지나면 목록 카드에 "N일 지남" 표시, 상세에 안내
  (업체에게는 "확인해 보세요", 본인에게는 "필요 없으면 마감해 주세요")
- **90일** 지나면 목록·홈에서 접어두고 "모두 보기" 로 펼칠 수 있습니다
- 마감·진행중·완료된 요청은 상태가 이미 분명하므로 접지 않습니다

기준을 바꾸려면 `gori-app.js` 의 `STL_WARN`(30) · `STL_HIDE`(90) 를 고치세요.

### 연결이 안 될 때

서버에 못 붙으면 화면이 "아직 요청이 없어요" 로 보였습니다. 처음 온 사람은
플랫폼이 텅 비었다고 생각하고 나갑니다. 이제 연결 실패를 감지해서

- 하단에 안내 띠 + **다시 시도** 버튼 (하단 네비를 가리지 않게 높이를 잽니다)
- 목록에는 "불러오지 못했습니다 · 다시 시도"
- 인터넷이 끊기면 별도 문구, 복구되면 자동으로 다시 불러옵니다

**데이터가 진짜 0건일 때는 그대로 "아직 요청이 없어요"** 가 나옵니다. 둘을
구분합니다.

### 업체 온보딩 (`업체 등록`)

4단계 마법사로 통합돼 있습니다. 이전에는 등록·인증·관심분야·바로견적이 네 화면에
흩어져 있었습니다.

| 단계 | 내용 |
|---|---|
| 1 기본 정보 | 업체명·대표자·연락처·영업 지역·주소 |
| 2 취급 분야 | 8대분류 다중 선택 → **여기서 고른 분야의 요청 알림을 받습니다** · 품목·서비스·최소량·납기 |
| 3 인증 서류 | 사업자등록(체크섬 검증)·축산물 영업허가·HACCP → **입력하면 인증 심사가 자동 접수됩니다** |
| 4 사진·알림 | 사진 최대 6장(업로드 전 1600px·JPEG 82%로 자동 축소) · 소개 · 바로견적 참여 |

등록을 마치면 `suppliers` 저장 + `verifications` 자동 신청 + `supplier_prefs` 알림 설정이
한 번에 처리됩니다. 저장소 버킷이 없으면 사진만 건너뛰고 나머지는 정상 등록됩니다.

### 관리자 콘솔 (`/admin.html`)

각 표 위에 **검색칸**이 있습니다. 업체명·품목·지역·연락처 등 표에 보이는 값이면
무엇이든 걸러집니다. 띄어쓰기로 여러 단어를 넣으면 모두 포함된 행만 남습니다.

Supabase Auth 로그인 + `admins` 표 대조로 접근을 통제합니다.
프론트엔드 비밀번호가 아니라 실제 계정 인증입니다.

| 탭 | 기능 |
|---|---|
| 대시보드 | 요청·견적·거래·업체 현황, 인증 대기·시세 미입력 알림 |
| 인증 심사 | 사업자·HACCP·축산물허가 승인/반려 → 업체 배지 자동 반영 |
| 업체 | 목록·수동 인증·삭제 |
| 요청 / 견적 / 거래 | 조회, 거래 상태 변경 |
| 당일알바 / 후기 | 조회·삭제 |
| 시세 | **입력·수정·삭제** — 여기 입력한 값이 홈 상단과 견적 「시세 대비 %」에 사용됩니다 |

스크립트는 **추가 전용**입니다. `DROP` / `DELETE` / `TRUNCATE` 가 없고, 기존 컬럼을
변경하지 않으며, 여러 번 실행해도 안전합니다.

실행 전에도 사이트는 정상 동작합니다. 신규 테이블이 필요한 화면에는 안내 문구가 뜨고,
요청 등록은 기존 컬럼만으로 자동 저장됩니다.

### 레거시 관리 화면 (`dashboard` / `suppliers` / `purchase_request` / `jobs`)

이 네 페이지는 "관리" 화면인데 **로그인 절차가 전혀 없었습니다.** 주소만 알면
누구나 열 수 있었고, 업체·요청·구인공고를 **삭제하는 버튼까지 그대로 눌렸습니다.**
`admin-gate.js` 를 붙여 `admin.html` 과 같은 기준(Supabase 로그인 + `admins` 표
등록)으로 막았고, `robots.txt` 로 색인도 차단했습니다.

로그인 전에는 본문이 통째로 가려지고 로그인 상자만 나옵니다.

**다만 이것은 화면 차단입니다.** 익명 키로 API 를 직접 호출하는 것은 막지 못합니다.
데이터 자체를 지키려면 아래 RLS 를 반드시 켜야 합니다.

## ⚠️ 컨설팅 결제 (`meat_insight_apply.html`)

이 페이지는 **고리가 직접 파는 유료 컨설팅·자료**를 결제받는 화면입니다.
토스페이먼츠로 카드·카카오페이·네이버페이·무통장입금을 받고, 가격은 20만원 ·
150만원 등으로 표시됩니다.

**지금은 테스트 키입니다.** `TOSS_CLIENT_KEY` 가 `test_ck_...` 로 시작해서 실제
결제가 이루어지지 않습니다. 그 상태로 손님이 카드로 신청하면 결제한 줄 알고
기다리게 되므로, 테스트 키일 때는 화면에 안내를 띄우고 카드·간편결제 선택지를
잠갔습니다. **실제 키를 넣으면 안내와 잠금이 저절로 사라집니다.**

실제 결제를 켜기 전에 확인하세요.

- **통신판매업 신고번호**가 반드시 있어야 합니다 (전자상거래법 제12조). `site-info.js`
  의 `mailOrder` 를 채워주세요.
- `terms.html` **제13조**에 유료 서비스 조항(가격·부가세·청약철회·환불 기한)을,
  `privacy.html` 에 결제 정보 수집·토스페이먼츠 위탁·전자상거래법 보관 기간(5년)을
  넣어두었습니다. 실제 운영 방식과 다르면 고쳐주세요.
- 이용약관 제5조는 "업체와의 거래에서는 중개자, 유료 서비스는 계약 당사자" 로
  구분해 두었습니다.

## 접근성 · 성능

**접근성** — `gori-app.js` 의 접근성 층이 다음을 처리합니다.
- `onclick` 만 달린 `<div>`(카테고리 타일·카드·푸터 링크 등, 홈에만 36개)에
  `tabindex`·`role="button"`·Enter/Space 처리를 자동으로 붙입니다. 새로 그려지는
  카드도 MutationObserver 로 계속 따라갑니다.
- 본문 바로가기 링크, `<main>` 랜드마크, 화면마다 `h1`(디자인상 없으면 숨은 제목),
  화면 전환 시 `aria-live` 안내.
- 포커스 링 3px. `index.html` 의 `.fi` · `.hs-input` · `.gh-s-in` 이 `outline:none`
  을 걸어 검색·입력칸에 포커스 표시가 아예 없었는데, 우선순위를 올려 되살렸습니다.

**레거시 콘텐츠 페이지** — `meat_insight_*` 6개는 옛 브랜드 그대로라 약관·방침
링크도 사업자 정보도 없었습니다. 디자인은 건드리지 않고 `legacy-chrome.js` 로
공통 꼬리말(고리 홈·이용약관·개인정보처리방침·사업자 정보)만 붙였습니다.

**성능** — 초기 로드는 gzip 기준 약 120KB 입니다.
- 구글 폰트(Noto Sans KR 6종 + Noto Serif KR)를 제거했습니다. `--serif` 가 이미
  `var(--font)` 로 바뀌어 있어 **어디에도 쓰이지 않으면서 렌더링만 막고** 있었습니다.
  Pretendard 뒤의 대체 폰트로는 그대로 남아 있어, 기기에 설치돼 있으면 쓰입니다.
- Supabase 스크립트를 `<head>` 에서 본문 스크립트 직전으로 옮겼습니다. `<head>` 에
  있으면 HTML 파싱이 CDN 응답을 기다립니다. 이제 head 에 렌더링을 막는 스크립트가
  없습니다.
- Supabase 프로젝트와 CDN 에 `preconnect` 를 걸었습니다.
- 공유 이미지 `og.png`(345KB) → `og.jpg`(54KB). 이미지 안의 "검증된 축산 업체"
  문구도 사이트와 같게 "조건이 맞는" 으로 고쳤습니다.

## ⚠️ 보안 점검 필요 — RLS 를 켜세요

**아직 하지 않았다면 이것이 가장 급합니다.**

`suppliers.html` · `jobs.html` · `purchase_request.html` 은 브라우저에 노출되는 anon 키로
`DELETE` 를 실행합니다. 화면은 `admin-gate.js` 로 막았지만, **anon 키로 REST API 를
직접 호출하는 것은 화면 차단으로 막을 수 없습니다.** 지금은 URL 과 키만 알면
누구나 업체·요청·구인공고를 지울 수 있는 상태입니다. (anon 키는 원래 공개되는
값이라, 브라우저 개발자도구에서 바로 보입니다.)

**해야 할 일** — `db/phase4_admin.sql` 의 **5번 블록(기존 테이블 RLS)** 주석을 풀고
Supabase SQL Editor 에서 실행하세요. 실행하면
- 요청·업체·공고는 누구나 **읽을** 수 있고 (사이트가 그대로 동작),
- **수정·삭제는 본인 것 또는 관리자만** 가능해집니다.

실행 후 사이트를 한 바퀴 돌며 요청 등록 · 견적 발송 · 업체 등록이 되는지
확인해 주세요.
