# 골프올인원 (GOLF ALL-IN-ONE)

골프 중개 플랫폼입니다 — 손님이 요청을 넣으면 운영자가 업체에 배정하고,
업체가 견적을 내면 손님이 나란히 보고 고릅니다. 업체가 없어도 회원끼리
되는 자리가 다섯 있습니다(조인 · 중고 직거래 · 게시판 · 구인구직 ·
구합니다 글).

**storeway.co.kr** · 정적 HTML + Vercel 서버리스 함수 + Supabase

---

## ⚠️ 아직 영업 전입니다

`build.js` 의 `SITE_LIVE` 가 `false` 라 **모든 화면에 noindex** 가 붙고
`robots.txt` 가 전부 막습니다. 손님이 무엇을 적어 보낼 수 있는 자리도
아직 하나도 안 열려 있습니다(Supabase 환경변수가 없습니다).

문을 여시려면 **`CLAUDE.md` 의 「문 여는 날 같이 해야 하는 것」** 을
그대로 하셔야 합니다. 지금 무엇이 비었는지는 세어 줍니다 —

```
node tools/check-open.js
```

⚠️ `SITE_LIVE` 만 켜면 **사업자 정보 없이 영업하는 꼴**이 되고
전자상거래법 제10조입니다. 그래서 빌드가 멈춰 세웁니다.

## 세우고 돌려 보기

`npm install` 이 없습니다 — 의존성을 안 씁니다(Node 와 저장소뿐).

```
node build.js          화면을 찍습니다 (결과도 커밋합니다 — Vercel 이 그 파일을 섬깁니다)
node tools/ship.js     검사 묶음 전부 (초록일 때만 올립니다)
node tools/shot-desk.js  로그인해야 나오는 화면을 찍어 봅니다 (검사가 아니라 보는 도구)
```

⚠️⚠️ **검사가 도는 동안 커밋하지 마세요.** `test-providers` · `test-course`
가 가짜 씨앗을 꽂았다 되돌리는 구간이 있어서, 그 중간 상태를 커밋하면
**없는 회사의 화면**이 공개 저장소에 올라갑니다(2026-11-09 에 실제로
그랬습니다).

## 올리는 법 — 올리는 것이 곧 배포입니다

`main` 이 움직이면 손님 화면이 바뀝니다. 길은 하나입니다 —

**GitHub → Actions → "검사 (배포는 단추로)" → Run workflow → deploy 를 true 로**
(손으로는 `node tools/ship.js --merge`)

작업 브랜치에 push 해도 `main` 은 **저절로 안 움직입니다.** 잘못
올라갔으면 `git revert` 로 **되돌린 커밋을 새로 올립니다**(force 로
밀면 손님이 받아 간 자산 주소가 사라집니다).

⚠️ `main` 이 움직여도 Vercel 의 **Production Branch 가 `main`** 이고
그 배포가 **Preview 가 아니라 Production** 이라야 손님에게 나갑니다
(`DEPLOY.md` 5-1 — 2026-11-07 에 그것 때문에 며칠 헤맸습니다).

