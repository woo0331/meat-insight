## 3. 작업 3 — DB 마이그레이션 **0066** (완성 · 검사 통과)

새 표 다섯 · 보기 둘 · 문 셋 · 트리거 하나 · `teetime` 에 칸 하나.

| | |
|---|---|
| `course` | 마스터. **`id`(uuid)와 `slug` 를 가릅니다** — 다른 표는 id 를 가리키고 주소만 slug (운영자가 고칠 수 있는 값) |
| `course_alias` | 같은 곳의 다른 이름 — **운영자가 확인한 것만** |
| `course_source` | 어느 출처의 어느 줄에서 왔나 (한 곳이 여러 출처에서 올 수 있어 표를 갈랐습니다) |
| `import_batch` | 어느 파일을 언제 넣었나 (`source_id` + `sha256` unique → **멱등**) |
| `import_row_issue` | 왜 안 들어갔나 |
| `v_course_public` | 공개로 읽는 **길 하나**. 가린 것은 안 나가고 **출처 · 기준일을 같이** 냅니다 |
| `v_course_count` | 집계 — **목록 보기 위에** 세워 조건이 구조적으로 못 어긋납니다 |
| `save_course` · `move_course` · `link_course_alias` | **전부 운영자만** |
| `teetime.course_id` | nullable. **글자 칸은 그대로 둡니다** |

지킨 규칙

- **표에 정책도 GRANT 도 하나도 없습니다.** 공개는 보기 하나, 쓰기는 문 셋,
  들여오기는 SQL 편집기에서 임자 권한으로.
- **제휴가 필요한 값은 칸을 아예 안 만들었습니다** — 실시간 잔여 티타임 ·
  그린피 · 회원권 호가 · 상품 재고. 칸이 있으면 누군가 채웁니다.
- **이름 정규화는 `course_norm()` 한 곳**이고 `name_norm` 은 generated 칸입니다.
  ⚠️ 처음에 JS 와 SQL 두 곳에 두었다가 **한쪽만 "컨트리클럽→cc" 를 해서**
  들여온 값과 트리거가 세는 값이 조용히 달라질 참이었습니다 (티타임이 영영
  안 이어지고 에러도 안 납니다). 지금은 검사가 **그 파일에서 JS 함수를 꺼내
  돌려** 둘을 맞춰 봅니다.
- **티타임 잇기는 이름이 정확히 맞을 때만**이고 못 찾으면 null 입니다.
  비슷한 이름으로 추측해 이으면 손님이 **다른 골프장을 예약**합니다.

들여오기 · 되돌리기

```
node tools/make-import-sql.js
  → data/staging/import_courses.sql     멱등 (두 번 넣어도 안 늘어남)
  → data/staging/rollback_courses.sql   그 묶음만 되돌리기
node tools/make-import-sql.js --dry-run  몇 줄이 나올지만 셈
```

⚠️ **FIXTURE 줄 · 출처 없는 줄 · 영업상태를 모르는 줄은 거절합니다.**
⚠️ **운영자가 가린 것은 다시 넣어도 안 되살아납니다.**
⚠️ **slug 는 안 덮습니다** (운영자가 고쳐 둔 주소를 지킵니다).

지킨 규칙

- **"예약 가능" · "공식 제휴" · "공식 파트너" 를 한 글자도 안 적습니다.**

- **출처와 기준일을 그 자리에서** 말하고 "저희가 직접 확인한 값이 아닙니다"

- **좌표가 있을 때만** 지도로 가는 길을 냅니다 (없는데 이름으로 열면
  엉뚱한 곳이 나옵니다).
- **폐업은 맨 위에서** 말합니다 (아래에 묻어 두면 손님이 전화를 겁니다).
- 카드는 `amCourseGrid()` **한 함수**이고 빌드와 브라우저가 같이 부릅니다.
- 0곳이면 **0곳이라고 말하고** 지금 되는 것(부킹 요청 · 올라온 티타임)을 같이 냅니다.
