### 막힌 지점
- ⚠️ **로그인 없이 조회(⑤-2)는 운영에서 못 켭니다.** 인증번호를 보낼 문자 발송사가 정해지지 않아 어댑터가 **테스트용 하나뿐**이고, 그것은 운영(production)에서 스스로 꺼집니다(`api/_lookup.js`). 그래서 운영에서 고객이 진행 상태를 보는 길은 지금 **로그인(메일 링크) → 신청번호 + 연락처로 내 신청 가져오기 → /my** 하나입니다.
- **실제 화면 + 실제 DB 를 한 번에** 눌러 보는 것은 못 했습니다. 이 환경에 PostgREST · Supabase 로컬 스택이 없어, 화면은 가짜 서버로 · DB 는 SQL 로 나눠 검증했습니다. 이어 붙인 확인은 **프리뷰(테스트용 Supabase)** 가 있어야 합니다.
- 운영 `/admin` 1번 칸(환경변수 · 판 번호 · 버킷)은 운영 로그인이 필요해 못 봤습니다. 운영 `/api/session` 은 `auth:false · restoration:true` — `STOREWAY_ACCOUNTS_OPEN` 이 꺼져 있습니다.
