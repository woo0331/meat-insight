## 3. 바꾼 화면

| 화면 | 바뀐 점 |
|---|---|
| 홈 | 단계 카드 4장 사진(개업 준비 · POS · 열쇠 인계 · 비워지는 매장) PC 4열 · 모바일 2열 · 카드 전체가 링크 / 업종 11장 각기 다른 사진 + "전체 업종 보기" 별도 칸 / 양도양수: 대표 배너 사진 + "매장 찾기 / 내 매장 넘기기" 사진 카드 둘, 권리금은 보조 링크 / 운영 작은 사진 / 세부 서비스는 훑어보는 링크 |
| `/startup` · 업종 상세 14 | 업종 사진 카드 · 새로 창업 / 기존 매장 인수 사진 카드(✓ 선택됨) · 장비 사진 · 로드맵은 "지금 할 일 · 다음 단계" 먼저(나머지 접힘) · 창업비 계산 단추 |
| `/operation` | 고민 카드 4장 사진(비용 · 시설 · 인력 · 홍보는 월넛 면) · 사진 높이 · 주 단추 정렬 · 모바일 1열 · 계산도구 "넣는 값 → 얻는 결과" |
| `/transfer` | 받는 분 / 넘기는 분 사진 카드 · 매물 0건은 실제 건수 + 권리금 계산 · 인수 계약 가이드 · 양도 준비로 / 계약 · 세무 · 법률은 "받는 도움"이 먼저 |
| `/closure` · 업종 상세 14 | 상황 4개 사진 카드(펼쳐 둠) · 철거 / 원상복구 사진 분리 · 분야 · 업종 고르개 공통 카드 · 집기 처분은 기존 품목 선택(`/assets?p=pick`) |
| 여러 서비스 함께 고르기 | PC 는 목록 **옆** 요약(sticky), 모바일은 개수가 보이는 **접이식** 요약 · 인테리어 · POS · 키오스크 · 가구 등 작은 사진 · 카드 전체 선택 · 개별 해제 · 전부 해제 · 새로고침 뒤 유지 · 접수가 닫혀 있으면 "접수 안내 보기" |
| `/providers` + 분야 17 | 분야마다 다른 대표 사진 · 예시 업체는 "예시" 딱지 그대로 |
| `/stores` · `/assets` | 결과 수가 거르개 **앞** · "전체 0건" / "조건 때문에 0건" 구분 · 품목 안내 사진은 "실제 매물 아님" 표시 |
| `/sell` | 매장 · 점포 / 시설 · 장비 사진 탭 · "필수 n / 6" 진행 표시 |
| `/tools` | 카드마다 "넣는 값 → 얻는 결과" (실제 입력 칸 이름에서) |
| `/content` | 맨 위 대표 글 셋 사진 카드(날짜순 · 분류 안 겹치게) |
| `/content/:slug` · `/c/:cat` | 그 분류의 연출 사진을 머리에 (목차 · 관련 글은 원래 있음) |
| `/franchise` | 분류 12장에 업종 공통 사진 (브랜드 사진이 아님 · 브랜드는 0개 그대로) |
| `/search` | 결과 종류와 건수를 맨 위 한 줄로 (눌러서 그 묶음으로) |
| `/sample` | 예시 다음에 입점 절차 셋 + `/join` 으로 가는 길 |
| 아래 네비 | `/search` 에서 "마이" 가 켜지던 것 → "서비스" |

`/support` · `/my` · `/intake` · `/quote` · `/join` · `/about` · `/faq` · 약관은 이미 "상태 · 다음 행동 먼저 / 목차" 짜임새라 구조는 그대로 두었습니다.

## 4. 검수

- `node tools/ship.js --check-only` — **22묶음 전부 통과** (마지막 실행 23분 14초)
- 주요 36개 화면 × 1440 / 390 / 360px — 가로 넘침 0 · 깨진 이미지 0 · 스크립트 오류 0
- 모바일(390 · 360) 하단 고정 띠 · 아래 네비와 요약 단추가 겹치지 않음 — 전문관 넷 모두 띠 위로 올려 누를 수 있음
- 실제로 눌러 본 길: 홈 → 각 전문관 · 양도양수 두 경로 · 폐업 상황 넷 · 검색 · 거르개 · 0건 · 고르기 0개 / 여러 개 / 개별 해제 / 전부 해제 / 새로고침 유지 · 접수 안내 링크
- 운영 고객 데이터는 쓰지 않았습니다.

## 5. 못 한 것 · 남은 것

- **새 사진은 넣지 못했습니다.** 외부 사진 받기가 막혀 있어 권리가 확인된 기존 사진만 다시 썼습니다. 사진이 없는 자리는 월넛 면 + 아이콘으로 높이를 맞췄습니다.
  - 빠진 장면: 주점(바 카운터) · 뷰티(네일 작업대) · 학원(교실) · 반려동물(펫 미용대) · 소매(진열대) · 숙박(객실) · 온라인 판매(포장 작업대) · 메뉴 촬영(홍보) · 간판 · 노무 · 재고 · 지원사업 · 인터넷
  - 파일을 `img/` 에 넣고 `js/data/photos.js` 에 한 줄 적으면 화면 코드는 안 고쳐도 됩니다.
- Preview 주소가 실제로 열리는지는 확인하지 못했습니다 (Vercel 보호 · 이 환경에서 닿지 않음).
- PC · 모바일 캡처는 화면마다 따로 대표님께 보냈습니다. 긴 화면은 업로드 한도로 윗부분 7,900px 까지입니다.
