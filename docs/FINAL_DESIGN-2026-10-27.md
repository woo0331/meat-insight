## 0. 먼저 보고드릴 것 — 3D 에셋

> §3-D — *"실제 3D 이미지 에셋을 사용한다 · **3D 에셋 생성 수단이
> 없다면 먼저 확인하고 보고한다** · 무관한 아이콘이나 품질이 낮은
> 이미지를 임의로 사용하지 않는다."*

**이 작업 환경에는 3D 이미지를 만드는 도구가 없습니다.** 그리고
받아 오는 것은 이 저장소가 막고 있습니다 —

| 길 | 왜 막혔나 |
|---|---|
| 3D 렌더 · AI 이미지 생성 | 이 환경에 그런 도구가 없습니다 |
| 스톡 3D 아이콘 내려받기 | 이미지 지시서 §4 — "사용 권한이 확인된 이미지만" |
| 비슷한 아이콘을 아무거나 | §3-D 가 직접 금지 · 이 저장소 절대 규칙 1 |

**그래서 품질이 낮은 이미지를 쓰는 대신, 이 저장소가 직접 그려 둔
컬러 아이콘(`iconArt()` 35장)을 시안의 카드 짜임새에 맞게 키우고
입체감을 입혔습니다.** 받아 온 그림이 아니라 전부 여기서 그린
SVG 라 저작권 · 라이선스 문제가 없고, 인라인이라 **내려받기 0건**
입니다.

```
크기    44px → 76px (타일 76×76 · 시안과 같은 비중)
면      흰색 → 웜 그라디언트 (#FFFFFF → 아이보리 → #F0E3D2)
깊이    타일에 안쪽 하이라이트 + 바깥 그림자
        그림(svg) 자체에 drop-shadow — 타일에만 걸면 네모만 뜨고
        그림은 평평하게 남습니다
색      브라운 한 벌 (--ia-1 · --ia-2 두 변수로만)
```

⚠️ **시안의 진짜 3D 렌더와는 다릅니다.** 두 톤 벡터에 그림자를 입힌
것이라 질감 · 반사는 없습니다. **권한이 확인된 3D 에셋(투명 배경
WebP · PNG)을 주시면 `js/data/photos.js` 의 자리에 파일만 넣어
바꿀 수 있습니다** — 그때도 카드 짜임새 · 이름 · 설명 · 버튼은
그대로입니다 (§3-D "아이콘 이미지가 없더라도 카테고리 이름과 기능은
정상 동작").

### 추가한 3D 아이콘 에셋 — **0개** (§7)

새로 만들어 넣은 이미지 파일이 **하나도 없습니다.** 쓴 것은 이
저장소가 전부터 들고 있던 **인라인 SVG 35장**(`iconArt()`)이고,
그중 직접 서비스 구간이 쓰는 여덟은 —

```

```

⚠️ 여덟 다 시안이 적은 그림과 **뜻이 같습니다.** 크기 · 비율은
`tools/fit-icons.js` 가 재서 맞춰 둔 표(`IA_FIT`)를 그대로 쓰므로
**서른다섯 장이 전부 같은 크기**로 그려집니다.

## 3. 시안과 다르게 둔 것과 그 까닭

> §1 — *"이미지에 있는 임의의 문구, 숫자, 서비스명보다 **실제 사이트의
> 데이터를 우선한다**."*

| 시안 | 지금 | 까닭 |
|---|---|---|
| 카드 설명 "주방기기, 냉난방, 집기, 가구, 보안매뉴 등" | 그 분류가 **실제로 들고 있는 하위 서비스** | 시안 글은 디자인 예시입니다. 인테리어는 "인테리어, 설계, 전기, 배관, 가스 등" 처럼 `catalog.js` 의 `items` 에서 옵니다 |
| 시설 · 장비 설명 | **"업종마다 다릅니다"** | 이 분류는 하위가 **업종에서** 옵니다. 모든 업종 장비를 합쳐 앞 다섯을 내면 **주방기기 · 냉장 · 냉동 · 조리기기**가 앞에 서서 미용실 · 학원 사장님께 "여긴 내 자리가 아니네" 가 됩니다 |
| 히어로 "지역별 맞춤 업체" | **"지역 · 업종으로 찾기"** | 등록된 업체가 **0곳**입니다. "맞춤 업체" 는 있는 것처럼 읽힙니다 (절대 규칙 1 · 표시광고법 제3조) |
| 히어로 "26개 서비스" | **"서비스 분야 26개"** (세는 값) | 지금 26 이 맞지만 손으로 적으면 분류를 늘릴 때 조용히 틀립니다. `AM_CATS` 를 그 자리에서 셉니다 |
| 헤더 `로그인` | **내 기록**(`/my`) | 로그인이 아직 `auth:false` 라 만들면 눌러도 아무 일이 안 납니다. 자리(`.hd-auth`)는 열려 있어 DB 를 켜시는 날 저절로 나옵니다 |
| 가이드 카드 사진 | **없음** | 권한이 확인된 사진이 없습니다. 아무 사진이나 깔면 업종이 드러납니다 |
| 사진 속 손글씨 | **안 넣음** | 사진에 글자를 합성하지 않습니다 — 폭마다 대비가 달라지고 읽어 주는 프로그램이 못 읽습니다 |

## 4. 기존 기능 보존 — **눌러서 확인했습니다** (§5 · §6⑦⑧)

```
✅ 메인 링크 24가지가 전부 실제 주소 (끊긴 것 0)
✅ 직접 서비스 카드 8장이 전부 분야 화면으로
      /providers/interior · equip · it · admin · staff · marketing
      · demolish · restore
✅ 창업 준비에 고를 칸 18개
✅ 두 개 고르면 2개  →  하나 해제하면 1개
✅ 메인이 고르신 서비스를 그 자리에서 냅니다 (2개)
✅ 신청 단추가 고른 것을 들고 갑니다
      /quote?side=start&sv=interior/interior,interior/sign
✅ 신청 화면이 고른 2개를 되읽습니다
✅ 검색 칸이 있습니다
✅ 전체 보기 단추 셋 → /providers · /tools · /content
✅ 계산기 화면이 뜹니다 (/tools/bep)
✅ JS 에러 0
```

⚠️ **`/tools` 로 가는 길이 메인 본문에 한 곳도 없었습니다** (헤더
메뉴와 푸터뿐). 시안이 "계산도구 전체 보기" 를 그려 둔 까닭이고,
넣으면서 그 길이 생겼습니다.

### ⚠️ 한 가지 밝혀 둘 것 — "서비스 선택" 이 있던 자리

> §3-D — *"기존 서비스 선택 기능을 반드시 유지한다 · 삭제하거나
> 단순 링크로 대체하지 않는다."*

**메인의 여덟 카드는 전에도 링크였고 지금도 링크입니다.** 고르는
기능(체크 · 복수 선택 · 해제 · 바구니 · 신청 전달)은 **전문관 네
화면**(`/startup` · `/operation` · `/transfer` · `/closure`)에
있고, 거기는 **한 줄도 안 건드렸습니다** — 위에서 18칸을 눌러
확인했습니다.

메인이 하는 일은 ① 분야 화면으로 보내는 것과 ② **이미 고르신 것이
있으면 그 자리에서 보여 주고 신청으로 보내는 것**(`HomePicked()`)
입니다. 메인 카드에 체크칸을 **더하지 않았습니다** — 그건 디자인이
아니라 기능 추가라, §5 대로 먼저 여쭙니다.

### 전수 점검이 잡은 것 하나 — **제 작업 탓이 아니었습니다**

```
❌ 고르개 딱지가 칸보다 긺 1건
   매물 내놓기 — 매장 › "매장 양도 — 권리금을 받고 넘깁니다"  229px > 214px (320px 폭)
```

`/sell` 의 거래 방식 고르개입니다. **직전 커밋을 따로 빌드해서 같은
자리를 재 봤더니 거기서도 똑같이 걸렸습니다** — 이번 디자인 작업과
무관하게 전부터 있던 것이고, 며칠 전 전수 점검에 320px 을 더하면서
드러난 자리입니다.

```
지금(내 변경)  320px  ❌ 229>214
직전 커밋      320px  ❌ 229>214   ← 같습니다
```

⚠️ `<select>` 안은 **낱말 잘림 검사에도 가로 스크롤 검사에도 안
걸립니다** — 이 저장소가 네 번 겪은 자리입니다. 딱지 두 줄을 줄여
고쳤습니다 (뜻은 그대로) —

```
매장 양도 — 권리금을 받고 넘깁니다  →  매장 양도 — 권리금 받고 넘기기
임대 — 보증금 · 월세로 내놓습니다   →  임대 — 보증금 · 월세로 내놓기
```

## 7. 운영 배포 전에 확인하실 것

1. **배포는 아직 안 했습니다.** 이 저장소는 작업 브랜치에 올리면
   CI 가 검사를 돌리고 스스로 `main` 으로 합칩니다 — 즉 **올리는
   것이 곧 배포**입니다. 그래서 커밋까지만 해 두었습니다.
2. **3D 에셋** — 위 §0. 권한이 확인된 파일을 주시면 코드를 거의
   안 고치고 바꿉니다.
3. **사업자 정보 여덟 칸**이 아직 비어 있습니다 (전자상거래법
   제10조). 이번 작업과 무관하게 영업 전에 필요합니다.
4. 시안의 **하위 화면**은 오지 않았습니다 — 이번에 고친 것은
   **메인 한 화면**이고, 나머지 화면은 공통 헤더 · 푸터 · 토큰만
   같이 움직입니다.
