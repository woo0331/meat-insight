> 2026-11-02 · 지시서 §0~§15 + `PHONEWAY_FINAL_reference_original.png`

## 0. 먼저 — 첨부 두 개 중 **하나만** 왔습니다

| 첨부 | 상태 |
|---|---|
| `PHONEWAY_FINAL_reference_original.png` | ✅ **보입니다.** 구도 · 색 · 간격을 여기서 읽고 맞췄습니다 |
| `PHONEWAY_FINAL_design_package.zip` | ❌ **안 왔습니다** — 업로드 폴더에 오늘 들어온 파일이 0개입니다 |

그래서 §11("ZIP 을 프로젝트에 저장하고 원본을 최종 시각 기준으로
활용한다")은 **못 했습니다.** 시안 **픽셀을 잘라 쓰는 것도** 파일이
있어야 되는 일이라, 히어로 기기와 서비스 그림은 **지금 가진 촬영본**
으로 갔습니다 (아래 §5). ZIP 을 다시 올려 주시면 **에셋만 갈아 끼웁니다** —
자리와 규격이 데이터(`WOW_PHOTOS` · `WOW_PHOTO_SLOTS`)에 있어서
코드는 한 줄도 안 고칩니다.

## 1. 변경 파일 (손으로 고친 것만)

```
css/tokens.css          맨 뒤에 화이트 중심 토큰 블록
css/pages.css           맨 뒤에 확정 디자인 블록 (헤더 · 히어로 · 서비스 · 상품 · 배너)
js/data/brand.js        enCut 한 줄 (워드마크에서 오렌지로 갈리는 자리)
js/components/chrome.js Logo() — 헤더 로고를 영문 워드마크로
js/pages/home.js        PwMarket() 에서 브랜드 로고 구간을 내림
build-pages.js          크롤러 본문에서 브랜드 묶음 뺌
check.js                브랜드 장수 검사 → **칩 개수** 검사로
tools/test-flows.js     브랜드 카드 클릭 → **거르개 칩** 클릭으로
img/svc-*.{jpg,webp}    여섯 장의 **바탕을 흰색으로** 다시 눌렀습니다
js/data/photos.js       그 여섯의 ?v= 갱신
```

되돌리시려면 **`css/tokens.css` 맨 뒤 블록**과 **`css/pages.css` 맨 뒤
블록** 둘입니다 — 그 둘만 지우면 웜 브라운으로 돌아갑니다.

## 2. §2 디자인 시스템 — 재 본 대비

```
제목 #231F20   흰 15.97 · 보조바탕(#F7F7F7) 15.12
본문 #333333   흰 12.63 · 보조바탕 11.96
보조 #666666   흰  5.74 · 보조바탕  5.43      (AA 4.5)
테두리 #EAEAEA · 그림자 0 1px 2px · 모서리 10 / 14px
```

⚠️⚠️ **`#F37021` 은 글자로 못 씁니다** (흰 바탕 2.39 · 흰 글자 2.94).
면 · 테두리 · 아이콘 · 선택 표시 전용이고, 흰 글자를 얹는 면은
`#D24601`, 밝은 바탕 위 글자는 `#A33E06` 입니다. 이 저장소가 밝은
브랜드색을 작은 글씨에 쓰다가 **다섯 번** 걸린 자리입니다.

⚠️⚠️ **구간 바탕이 흰색 ↔ #F7F7F7 둘뿐**이라 ΔE 가 **2.81** 입니다
(기준 2.5 · 칼날 위). 그래서 구간 사이에 **얇은 선**을 같이 둡니다 —
전수 점검의 "이웃한 두 구간이 붙어 보임" 은 보이는 테두리가 있으면
건너뛰고, 선은 §2 의 "얇고 균일한 테두리" 이기도 합니다.

## 3. PC 구현 결과 (§3~§8)

| 자리 | 한 것 |
|---|---|
| §3 헤더 윗줄 | **흰색**으로 (앞 차수는 딥 브라운) · 왼쪽 시세 안내 · 오른쪽 둘 |
| §3 로고 | **PHONEWAY 워드마크** — `PHONE` 짙은 색 · `WAY` 오렌지 |
| §3 사업자 전용관 | **오렌지 테두리 알약** |
| §3 판매 신청 | 채운 오렌지 (짙은 쪽 — 흰 글자 4.59) |
| §4 히어로 | **흰 바탕 + 오른쪽 아래 오렌지 곡선** · 글 · 버튼 둘은 HTML |
| §5 안내 넷 | **흰 카드 띠** + 세로 구분선 + 오렌지 선 아이콘 (PC 4열 · 폰 2열) |
| §6 주요 서비스 | 흰 카드 **다섯**이 한 줄 · 얇은 테두리 · 우측 하단 원형 화살표 |
| §7 상품 | 제목 **중고폰 둘러보기** · 브랜드 칩 **일곱** · 재고 0건이라 빈 상태 |
| §8 사업자 배너 | 상품 영역 **오른쪽** 딥 브라운 (글 기둥의 36%) → `/business` |

⚠️ **브랜드 로고 카드 구간을 내렸습니다.** 시안에서 제조사는
**거르개 칩**으로만 나옵니다. 로고 카드 여섯을 따로 두면 ① 같은 축이
한 화면에 두 벌이고 ② 재고 0건이라 그 여섯이 전부 `0대` 로 서서
첫 화면 다음이 빈 칸 여섯이 됩니다. `PwBrands()` 는 **안 지웠습니다**.

## 4. 모바일 구현 결과 (§9 · §10)

흰 헤더(로고 · 마이 · 찜 · 신청 · 메뉴) → 히어로(제목 · 버튼 둘 ·
기기 · 오렌지 곡선) → 안내 넷 2열 → 서비스 2열 → 상품 → 사업자 배너
전체 너비 → 이용 방법 → 푸터, 아래 고정 네비 다섯.

## 5. 원본과 **시각적으로 다른 부분** (§15-5)

| 시안 | 지금 | 까닭 |
|---|---|---|
| 히어로 스마트폰 **다섯 대** | **두 대** | 권한이 확인된 촬영본이 넷이고 그중 휴대폰이 둘입니다. ZIP 이 오면 늘립니다 |
| 서비스 이미지 5종(쇼핑백 · 수리 공구 · 시세 그래프 · 유심) | 사진 **셋** + 컬러 아이콘 **둘** | `svc-price` · `svc-mvno` 의 촬영본이 없습니다. `WOW_PHOTOS` 에 두 줄이면 코드를 안 고치고 사진이 됩니다 |
| 상단 바 `매장 찾기` · `고객센터` | **이용 안내** · **도움말** | 오프라인 매장 **0곳**이고 전화 창구가 없습니다(사업자 정보 여덟 칸이 빔) — §3 자신이 "허위 매장 목록에 연결하지 않는다" 고 적었고, §12 가 "실제 상태에 맞는 안내 페이지" 를 적었습니다. ⚠️ `WOW_BIZ.phone` 이 채워지는 날 이름만 되돌리시면 됩니다 |
| 헤더 `로그인` · `회원가입` | **자리만** (`#hdAuth`) | `/api/session` 이 `auth:false` 입니다. 환경변수가 들어가는 날 **코드를 한 줄도 안 고치고** 섭니다 |
| 헤더 `장바구니` | **없습니다** | 장바구니 표도 결제도 이 저장소에 없습니다. 아이콘만 걸면 눌러서 빈 화면입니다 (§12) |
| 상품 카드 4장 (아이폰 15 Pro 890,000원 …) | **빈 상태 화면** | 실제 재고 **0건**입니다. §7 이 직접 "디자인 예시" 라고 적었습니다 |
| 제목 `지금 인기 있는 중고폰` | **중고폰 둘러보기** | 조회 · 클릭을 하나도 모으지 않습니다 — §7 이 그 경우의 이름을 지정해 두었습니다 |
| 안내 배너 셋이 딥 브라운 | **흰 카드** | 헤더까지 흰색이 되면서 이 셋만 짙은 면으로 남아 결이 갈렸습니다 (§0-5 · §2) |
| 사이드바 작은 배너 둘이 딥 브라운 | **흰 카드** | §2 가 딥 브라운으로 정한 것은 **사업자 배너 하나**입니다. 수리 서비스 · 판매 진행 조회까지 짙게 두면 §0-5 에 걸리고, 폰에서는 짙은 덩이 **셋이 연달아** 섭니다 (찍어 보고 알았습니다) |
