## §4 서비스 카테고리 중복 · 누락 — 재 본 값

**"동일한 서비스가 여러 카테고리에 중복 등록"** — 하위 key 가 둘 이상
분류에 들어 있는 것이 **스물셋**입니다. 그런데 열어 보니 **중복이
아니라 서로 다른 일**입니다 —

```
interior/electric  전기 공사(설치)      restore/electric  전기 원상복구(철거)
it/pos             POS 도입             asset/pos         POS 중고 매각
                                        contract/pos      POS 계약 해지
supply/ingredient  식자재 공급          stock/ingredient  남은 재고 처리
```

⚠️ **지우면 안 됩니다.** 생애주기가 다르고 가는 업체가 다릅니다.
다만 **이름이 글자까지 같아서** 목록에서 나란히 보이면 가릴 수가
없습니다 — 그래서 고르는 목록에 둘이 같이 나오는지 재 봤고
**0건**이었습니다 (전문관마다 한쪽만 냅니다).

| 재 본 것 | 값 |
|---|---|
| 고르는 목록에 **같은 글자** 체크칸 | **0건** (창업 14 · 운영 88 전부 펼쳐서) |
| 상세 화면 없는 분류 | **0개** |
| 글 0편인 분류 | **`repair` 하나** — `ReadBand()` 가 구간째 빠집니다 |
| 서비스별 질문 있는 분류 | 14 / 26 |

## ⚠️ 접근성 — 같은 이름 체크칸 여덟 (§17)

`/operation` 묶음 여덟에 각각 "어떤 것이 필요한지 모르겠어요" 칸이
있습니다. 눈으로는 묶음 안이라 갈리는데, **읽어 주는 프로그램에는
똑같은 이름이 여덟 번** 들립니다 — 어느 분야 것인지 알 수가 없습니다.
