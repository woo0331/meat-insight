## 6. 중복 서비스 및 콘텐츠 (§4)

⚠️⚠️ **하나도 지우지 않았습니다.** §4 가 "기존 서비스 데이터를 임의
삭제하지 않는다 · 서비스 ID · 신청 기록 · 업체 연결을 보존한다" 고
적었고, 재 보니 **겹쳐 보이는 것이 실은 다른 단계**였습니다 —

```
interior/electric  공사할 때      restore/electric  되돌릴 때
it/pos  승계      asset/pos  파는 것      contract/pos  해지
asset/furniture  파는 것          waste/furniture  버리는 것
```

가는 업체가 다릅니다. 그래서 **지우는 대신 읽어 주는 이름에만**
묶음 이름을 붙였습니다 (위 A11y-7).

**화면 안의 중복은 줄였습니다** — 폐업에서 신청 단추 셋 → 하나,
양도양수에서 둘 → 하나, 패키지는 "신청" 에서 **"위 선택에 담기"** 로.
