## 1. 1순위 — 적용 묶음의 **틀린 설명 둘을 정정**했습니다

사장님이 잡으신 두 가지가 **둘 다 맞았습니다.** 세어서 확인했습니다.

### ① 「삭제 구문이 한 줄도 없습니다」 → 틀렸습니다

```
db/apply-all-1.sql  4994~4997
  drop table if exists device_cost
  drop table if exists device_check
  drop table if exists device_move
  drop table if exists device
```

이 넷은 **같은 묶음 안의 0020 이 만든 표**를 0024 가 걷어내는 것입니다
(앞 서비스 중고폰의 잔재). 운영 DB 에 **지금 없는 표**이고 기존 16개와
아무 상관이 없습니다 — 즉 **결론은 안전한 것이 맞았는데 근거가
거짓**이었습니다.

세어 보니 그 밖에도 —

| 무엇 | 몇 개 | 대상 |
|---|---|---|
| `drop view` | 76 | 우리 `v_*` 보기 |
| `drop policy` | 79 | 우리 표 (`account` … `watch`) |
| `drop trigger` | 35 | 위와 같고 하나가 `auth.users` |
| `drop constraint` | 26 | 우리 표의 check |
| `drop function` | 10 | 우리 함수 |
| `drop column` | 5 | `request` · `provider` |
| `drop type` | 2 | `device_*` |
| `drop index` | 1 | `provider_inhouse_idx` |
| `truncate` · `drop schema` · `drop database` · `drop role` | **0** | — |

**기존 16개 표 이름은 이 묶음 어디에도 한 번도 안 나옵니다** (16/16 0건).
`auth.users` 에 트리거를 하나 거는 것은 따로 밝혀 두었습니다.

### ② 「멈춘 파일은 통째로 되돌아갑니다」 → 틀렸습니다

마이그레이션 **81개 가운데 16개가 `begin`/`commit` 으로 안 감싸져**
있습니다 —

```
0001 0002 0003 0004 0005 0006 0015 0045
0071 0072 0073 0074 0075 0076 0080 0081
   조각 1번에 일곱 · 2번에 하나(0045) · 5번에 여덟 · 3·4번에는 없습니다
```

`alter type … add value` 처럼 트랜잭션 안에서 못 도는 구문이 들어 있어
**일부러** 안 감싼 것입니다. 그 열여섯이 중간에 멈추면 **앞부분이
적용된 채 남습니다.**

### ③ 「`schema_version` 이 없다 = 한 번도 안 돌았다」 → 단정이었습니다

그 표는 **0002 가** 만듭니다. 0001 이 중간에 멈추면 표 · 함수가 일부
생긴 채로 그 표만 없습니다.

### 고친 것

`db/resume.sql` 이 이제 ①~⑧ 을 내고, **임시 Postgres 에서 여섯 꼴로
눌러 봤습니다** (빈 DB · 0001 중간 멈춤 · 0024 · 0059 · 0070 · 0081).

- ④ **우리 표가 몇 개 있는지**를 따로 세어 「0001 이 중간에 멈춤」을 가립니다
- ⑤ **멈춘 번호가 그 열여섯에 드는지**를 말합니다
- ⑥ 들면 **이미 만들어진 객체 열둘**을 가장 나중 차례로 보여 줍니다

`db/README.md` 에 **0단계 — 백업**(대시보드 클릭 세 걸음 + `pg_dump`)과
**「이 묶음이 지우는 것」** 표를 더했습니다.

## 2. 2순위 — 지역별 골프장 정보 탭

### ⚠️ 먼저 — 이미지를 **못 받았습니다**

지시에 「첨부한 '지역별 골프장 · 날짜 자동 갱신' 이미지」라고 적혀
있었는데 **이 세션에 이미지가 오지 않았습니다.** 그래서 **글로 적어
주신 항목만** 보고 만들었고, 그림에만 있던 배치 · 색 · 간격은
**못 맞췄습니다.** 그림을 다시 보내 주시면 그 부분을 맞추겠습니다.

### 마이그레이션이 **한 줄도 없습니다**

`course`(0066)를 열어 보니 —

| 지시서가 요구한 것 | 어디 있나 |
|---|---|
| 사진 | `course.photo` (0081) |
| 위치 | `region` · `gu` · `addr` · `addr_road` |
| 홀 수 | `course.holes` |
| 유형 | `course.biz_kind` |
| 상세 | `/course/<slug>` (`pages/course.js`) |
| 공식 홈페이지 | `course.site_url` |

**전부 이미 있었습니다.** 0069 · 여행 해외지역에 이어 세 번째로
「새 칸이 필요하다」고 적기 전에 표를 열어 본 자리입니다.

### 만든 것

```
pages/category.js   courseTabs() · coursePane() · courseZero()
js/data/courses.js  amCourseCard() · amCourseCards() · amCourseChipRow()
                    amCourseList() · amCourseRegions() · amCoursePickCards()
js/courselist.js    탭 가르기 · 이름 찾기 · 지역 추리기 · 뒤로 가기
js/booking.js       pastCut() · freshen() · watchDay() · kstNow()
tools/pull-courses.js  photo → photo_url (PROVIDER_BUCKET)
css/app.css         .cstab* · .csc* · .csf*
```

### 지시 항목별로

| 요구 | 한 것 |
|---|---|
| 탭 둘 | `.cstab` — 링크이고 `?tab=course` 로 주소가 바뀝니다 |
| 지역별 사진 · 위치 · 홀 수 · 유형 · 상세 · 홈페이지 | 카드 한 함수 · 없는 값은 **줄째 뺍니다** |
| 이름 검색 + 지역 필터 | 양식(JS 꺼져도 GET) + 지역 칩(세어서 · 0곳 지역은 안 냄) |
| KST 오늘 기본 | `kstISO(0)` — 한국 밖 시간대 셋에서 **날짜 띠 글자를 맞춰** 봤습니다 |
| 7일 띠 + 달력 | 날 수는 `site.js` 의 `teeBoard` 한 곳 · 달력 끝은 `teeAhead` |
| 자정 넘김 · 복귀 갱신 | `watchDay()` — 30초마다 **날짜만** 보고, 복귀는 1분 넘었을 때만, `pageshow`(bfcache)도 |
| 미래 날짜 보존 | **지난 날짜만** 비웁니다 |
| 날짜 · 시간 거르개 → 티타임 탭 | 그대로 (전부터 있었습니다) |
| 오늘 지난 시각 제외 | `pastCut()` — **서버**가 거릅니다 |
| 닫힌 티타임 제외 | `v_teetime_open` 이 `state='open'` 으로 이미 거릅니다 |
| 0건이어도 골프장 정보는 보임 | 다른 탭이라 영향이 없습니다 |
| 날짜가 골프장 목록을 안 바꿈 | 검사가 **전 · 후 수를 재서** 봅니다 |
| PC · 모바일 | 3 / 2 / 1열 · 찍어서 확인 |

### 찍어 보고 고친 것 둘 (어떤 검사도 영원히 못 잡습니다)

1. **「공식 홈페이지」가 빨간 경고 단추로 보였습니다** — `.btn-bad` 는
   `--bad`(#B91C1C) 라 「내리기」 · 「신고」 자리의 색입니다. `.btn-line` 으로.
2. **폐업 카드가 분홍 바탕이라 오류처럼 보였습니다** — 폐업은 사실이지
   오류가 아닙니다. 바탕은 회색이고 **딱지만** 빨갛습니다.

### 검사가 잡은 것 둘 (제 코드 · 제 검사)

1. **칩 줄을 `pages/` 에만 두었더니 브라우저가 손댈 수 없었습니다** —
   `{"keys":[],"want":["seoul",…]}`. `amCourseChipRow()` 한 함수로 옮겨
   빌드와 `courselist.js` 가 같이 부릅니다.
2. **폰 누름 40px 검사가 멀쩡한 화면을 세 폭에서 떨어뜨렸습니다** —
   가려진 탭 안의 **높이 0** 단추 둘을 셌습니다. `tapsOk()` 가
   2026-11-09 에 고친 자리인데 **이 묶음만 안 고쳐져** 있었습니다.
   `getClientRects().length` 로 거르고, **20px 미끼**로 아직 잡는지
   확인했습니다 (멀쩡할 때 0건 · 20px 로 줄이면 1건).

## 3. 3순위 — 골프장 자료

### 자동 수집은 **막혀 있습니다**

```
CONNECT www.data.go.kr:443  →  HTTP/1.1 403 Forbidden
```

환경의 네트워크 정책입니다 (Vercel · Supabase 가 아닙니다).
오늘 시도까지 `data/staging/blocked_sources.csv` 에 적혀 있고
**받은 줄은 0건**입니다.

⚠️ 수를 채우려고 **다른 길로 돌아가지 않았습니다** — 기억에서 적은 줄은
출처가 없고, 출처 없는 시설은 지어낸 것과 구별되지 않습니다.

### 받는 구조는 완성했습니다

```
tools/add-course.js              손으로 확인한 한 줄을 더합니다
data/review/courses_review.csv   검토 묶음 (지금 0줄)
data/review/README.md            무엇이 있어야 한 줄로 치나
tools/make-import-sql.js         그 묶음도 같이 읽습니다
```

**거절하는 것** — 출처 URL 없음 · 확인 날짜 없음 · 앞날 · 「제휴」
「예약 가능」 「추천」 「공식 파트너」 「최저가」 「보장」 · 없는 지역 키 ·
좌표 · 같은 이름 같은 지역. **여덟 꼴로 눌러 봤습니다.**

되돌려 보기가 **제 도구의 구멍**을 하나 잡았습니다 — 처음에 `lat:""` 로
박아 두어 `--lat` 을 **아무 말 없이 버렸고** 그 가드는 죽은 코드였습니다.

### 덤으로 고친 것

**`site_url` 을 들여오기가 안 보내고 있었습니다** — `course` 에 칸이
0066 부터 있고 `v_course_public` 이 내는데, `make-import-sql.js` 가 그
칸을 빼고 있어 **영원히 비어 있었습니다**(「만들어 놓고 안 쓰는 칸」의
또 한 판). 지금은 같이 넣고 **빈 값으로는 안 덮습니다**.

## 4. 4순위 — 시연 환경

```
node tools/demo.js [포트]        켜기
rm -rf tools/demo tools/demo.js  한 번에 지우기
```

- 골프장 **열넷**을 심었습니다 (`tools/demo/data.js` 의 `COURSES`)
- 이름이 **티타임의 `course` 와 맞는지** `check.js` 가 켤 때마다 봅니다
- 띠에 **「사진은 분류 사진을 잘라 만든 예시」**를 적었습니다
- `makePhotos()` 가 골프장도 훑게 고쳤습니다 — 안 고쳤을 때 **아홉 장이
  404** 였습니다
- 운영 DB 에 닿는 길이 **없고** 쓰는 길은 전부 **403** 입니다

### 외부 배포 — **준비만** 했습니다

시연 서버는 `127.0.0.1` 에서만 열립니다. 밖에서 열려면 사장님의 선택이
필요합니다 (아래 「사장님이 고르실 일」).
