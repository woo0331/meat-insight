검사 열여섯이 개발 환경에서 전부 초록이었는데 CI 는 빨갰고 `main` 이
안 움직였습니다. 까닭은 `sitemap.xml` 한 줄 — `lastmod` 과 머리 주석에
**빌드한 날**이 들어가서, 10-19 에 빌드·커밋한 것과 10-20 에 CI 가
빌드한 것이 달라 `ship.js --ci` 의 "빌드 결과가 커밋과 같은가" 가
떨어졌습니다. **자정을 넘긴 밀기마다** 그렇게 됩니다.

- `lastmod` 은 이제 **글 예순여섯 편의 실제 `at`** 만 냅니다 (나머지
  주소는 안 냅니다 — 선택 항목이고, 없는 것이 틀린 것보다 낫습니다).
  163개 주소가 전부 "오늘 바뀌었다" 고 말하면 구글은 그 값을 무시합니다.
- HEAD 커밋 날짜로 바꾸는 것도 **안 됩니다** — 커밋하면 날짜가 바뀌어
  같은 고장이 모양만 바꿔 돌아옵니다. 빌드 결과는 소스에만 달려 있어야
  합니다.
- `checkSitemapDates()` 가 빌드마다 봅니다 (되돌려서 멈추는 것을
  확인했습니다). 두 번 돌려 `sitemap.xml` · `index.html` · 하위 화면이
  글자까지 같은 것도 확인했습니다.
- CI 로그를 못 읽은 것도 고쳤습니다 — GitHub 의 일감 로그는 blob
  저장소에서 와서 이 환경의 `gh` 가 안 닿습니다. `tools/ship.js` 가
  출력을 `GITHUB_STEP_SUMMARY` 에도 적게 했습니다 (API 로 읽힙니다).
