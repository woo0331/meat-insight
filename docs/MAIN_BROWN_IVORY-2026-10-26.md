## 1. 고친 파일은 **둘**입니다

| 파일 | 무엇 |
|---|---|
| `css/tokens.css` | 지시서가 숫자로 정한 다섯 + 포인트를 글자로 쓸 때의 짙은 쪽 |
| `css/pages.css` | 맨 뒤에 블록 하나 (색 · 그림자 · 글자 크기) + 오래된 홀 중괄호 하나 |

**그 밖에 바뀐 것은 전부 생성물**입니다 — 빌드가 다시 만든 HTML 167개와
`dist/`. 메인을 뺀 **166개 화면**은 **`?v=`(캐시 값) 네 줄 말고는 한 글자도** 안
바뀌었고, 메인 `index.html` 은 `?v=` 조차 빼면 **0줄**입니다.

```
js/ 변경 0줄 · db/ 변경 0줄 · api/ 변경 0줄 · tools/urls.json 그대로
```

→ 지시 1(섹션 구성 · 순서 · 서비스 카드 · 기능 · 동선 유지)과
지시 7(서비스 검색 · 계산도구 · 상담 신청 · 링크 · DB · API 변경 금지)은
**고칠 자리가 아예 없었습니다.**

## 2. 색 — 지시서의 다섯을 그대로 넣고 **전부 재 봤습니다**

```

--hm-bg2  #E9DDCD  섹션 배경(밀크 베이지)
```

| 글자색 | 아이보리 | 베이지 | 카드 |

AA 는 보통 글자 4.5 입니다. 그래서 **글자로 쓰는 포인트는
`--hm-pt-ink`(#7A512F)** 를 따로 두었습니다 — 이 저장소가 `--blue` ·
`--ops` · `--acc` 로 **네 번** 겪은 자리입니다.

### 포인트를 **하나로** 모았습니다

메인이 금빛(`--gold-text` #7A5633)과 새 포인트를 **ΔE 3.05** 로 둘 다
들고 있었습니다 — 거의 같은 브라운 둘은 통일이 아니라 흐림입니다.
`#view` 안에서만 금빛 글자 토큰을 포인트 쪽으로 돌려서 **머리말 ·
걸음 번호 · 분류 딱지 · 체크 아이콘이 한 색**이 됐습니다.

⚠️ **`html.ivh` 가 아니라 `html.ivh #view` 에 걸었습니다.** `html` 에
걸면 **헤더 · 푸터까지** 물들어 메인만 머리가 다른 사이트가 됩니다.

구간 · 글 · 단추 차례는 그대로입니다.

색을 따로 안 준 글이 **밝은 면에 밝은 글자**로 앉습니다.

## 5. 지나가다 찾은 것 — **홀 중괄호 하나** (고쳤습니다)

```
css/pages.css   { 2566   } 2567      ← 17일 동안 하나가 짝이 없었습니다
```

2026-10-09 커밋이 `@media (max-width:460px){` **여는 줄만** 지워서,
안쪽 한 줄이 **전 폭에서** 돌고 닫는 중괄호가 떠 있었습니다. CSS 파서가
맨 바깥의 홀 `}` 를 그냥 건너뛰어 **화면도 멀쩡했고 아무 검사도 안
잡았습니다.** 그 안의 `.msvc-ph-n` 은 화면에서 쓰는 곳이 **한 군데도
없어서**(JS 전체에 0건) 둘을 같이 지웠습니다 — **보이는 것은 한 픽셀도
안 바뀝니다.**

⚠️ 중괄호 짝은 `grep -o '{' | wc -l` 로 **세어 보세요.**
