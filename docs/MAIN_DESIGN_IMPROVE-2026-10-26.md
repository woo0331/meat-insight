> 2026-10-26 **"인수인계 메인페이지 최종 디자인 개선"** 지시서의 §6
> 여섯 항목입니다. 기준은 첨부하신 **비교 이미지의 오른쪽(수정 후)**
> 과 그 오른쪽에 달린 **개선 주석 일곱**입니다.

⚠️⚠️ **운영에 올리지 않았습니다.** 지시서 맨 끝이 "운영 DB 변경,
main 병합, 실제 배포는 내 승인 없이 진행하지 마" 라서 **작업
브랜치까지만** 올립니다. DB 는 한 줄도 안 건드렸습니다
(마이그레이션 추가 없음) · 주소도 그대로입니다.

똑같이 돌아옵니다.

## 2. 디자인 변경 — 시안 주석 일곱을 하나씩

### ① 메인 비주얼 — 주 단추가 **브라운**이 됐습니다

```
전   무료 견적 신청 = 샌드 골드 #F5D49A + 어두운 글자
지금 무료 견적 신청 = 에스프레소 브라운 #382820 + 크림 글자 (대비 13.6)
```

⚠️⚠️ **하단 CTA 는 골드 그대로입니다.** 거기는 짙은 브라운 면 위라
브라운 단추로 바꾸면 바탕에 묻힙니다 — "주요 버튼에 브라운" 은
**밝은 면 위에서** 지키는 규칙입니다.

### ② 서비스 카드 넷 — 짙은 채색 면에서 **밝은 카드**로

이번 작업에서 제일 큰 변화입니다.

| | 전 | 지금 |
|---|---|---|
| 카드 면 | 브라운 · 딥그린 · 퍼플 · 버건디 **짙은 그라디언트 넷** | **크림 #FFFDF9** 한 가지 + 브라운 선 |
| 사진 위 막 | 아래로 갈수록 **.96** (사진이 거의 안 보였습니다) | 위 .16 → 가운데 .02 → 아래 .12 |
| 글자 | 흰색 | 브라운 #30231C · 보조 #6B5A4E |
| 구분 색 | 카드 면 전체 | **번호 알약 · 아이콘 · 바로가기 알약 셋** |

⚠️⚠️ **구분 색을 없앤 것이 아닙니다** (2026-10-16 §2-1 "색상 구분은
반드시 유지"). 창업 브라운 · 운영 딥그린 · 양도양수 퍼플 · 폐업
버건디가 그대로 살아 있고 **검사도 그 규칙을 그대로** 봅니다 —
재는 자리만 카드 면에서 번호 알약으로 옮겼습니다.

### ⚠️⚠️ 사진 넉 장의 밝기를 **재서** 맞췄습니다

§1 의 "이미지 크롭과 밝기를 통일해 브랜드 일관성 확보" 입니다.
눈대중이 아니라 원본을 캔버스에 그려 평균을 냈습니다.

| 사진 | 밝기 전 → 후 | 채도 전 → 후 |
|---|---|---|
| `hero-startup` (창업) | 108.7 → **106.0** | 42.7 → **46.1** |
| `hero-ops` (운영) | 96.9 → **104.9** | 42.3 → **46.0** |
| `kind-pass` (양도양수) | 96.5 → **105.4** | 61.9 → **47.9** |
| `hero-closure` (폐업) | 115.3 → **107.0** | 35.8 → **44.0** |
| **편차** | 18.8 → **2.1** | 26.1 → **3.9** |

- 원본 파일은 **한 바이트도 안 고쳤습니다** — 화면에서만 맞춥니다.
- ⚠️⚠️ **재는 법** — 캔버스의 `ctx.filter` 에 CSS 와 **같은 필터
  문자열**을 넣고 그려서 평균을 냅니다 (규격이 같아 결과가 같습니다).
  `drawImage` 만 하면 CSS 필터가 **안 걸린 원본**을 재게 됩니다.
- ⚠️ **사진을 바꾸시면 다시 재서** 그 네 줄을 고치세요.

### ③ · ④ · ⑤ 아이콘 타일을 **한 벌로**

시안 주석 ③ 이 "브라운 톤 아이콘으로 브랜드 일관성 강화" 입니다.

| 묶음 | 전 | 지금 |
|---|---|---|
| 직접 서비스 찾기 여덟 | 58px · 모서리 18 · **배경 여덟 색** (앰버 · 슬레이트 · 블루 · 퍼플 · 틸 · 핑크 · 오렌지 · 틸) | **64px · 18 · 브라운 틴트 하나** |
| 계산도구 넷 | 76px · 모서리 22 · **아이콘 네 색** (#7A4A1F · #1F6B52 · #2F5D8A · #A8473F) | **64px · 18 · 브라운 #6A4E39** |
| 이용 방법 다섯 | 40px · **원형** · 골드 틴트 | **48px · 14 · 같은 브라운 틴트** |

⚠️⚠️ **이것은 2026-10-20 결정을 되돌린 것입니다.** 그때 직접 찾기
아이콘에 분류색을 붙이면서 "안 붙이면 여덟이 전부 같은 브라운으로
서서 서비스가 색으로 갈리지 않는다" 고 적어 두었습니다. 이번 시안이
**그 반대**를 직접 지시했고(§1 "아이콘 색상 · 배경 스타일 통일" ·
주석 ③), 구분은 **아이콘 모양과 이름**이 합니다. 되돌리시려면 맨 뒤
블록의 그 네 줄입니다.

⚠️ **색은 `--ia-1` · `--ia-2` 두 변수로만 들어옵니다** — `color` 만
바꾸면 컬러 아이콘은 제 기본값으로 그대로 섭니다. 선 아이콘은
`color` 를 보므로 **둘 다** 적었습니다.

### ⑥ 이용 가이드 — 썸네일 칸

카드마다 **그 글의 분류 아이콘**을 브라운 틴트 판(116px)에 얹었습니다.
카드 셋의 높이와 글 정렬이 같아졌습니다.

⚠️⚠️ **사진이 아닙니다.** 시안은 실사 썸네일인데 쓸 수 있는 사진이
없습니다 — 받아 오는 것은 이미지 지시서 §4 가 금지하고(권한이
확인된 것만), 아무 사진이나 깔면 **업종이 드러나** 다른 업종
사장님께 "여긴 내 자리가 아니네" 가 됩니다. 지시서 §3 의 "허위 ·
무단 생성 금지" 와 같은 자리입니다. **권한 있는 사진을 주시면 이
칸이 그대로 액자입니다** (코드는 안 고칩니다).

### ⑦ 하단 CTA

이미 짙은 브라운 면 + 골드 단추였습니다. 주 단추에 그림자만 얹어
강조를 올렸습니다.

### 그 밖에 — 카드 면을 한 벌로

`.bdir-c` 가 혼자 **순백(#FFFFFF)** 이고 나머지가 크림(#FFFDF9)

## 6. 남아 있는 문제

| 무엇 | 왜 |
|---|---|
| **가이드 카드의 실사 썸네일** | 권한이 확인된 사진이 없습니다. 지금은 우리가 그린 분류 아이콘입니다 — 사진을 주시면 코드를 안 고치고 바뀝니다 |
| **하단 CTA 오른쪽 사진** | 시안에 있고 자리(`cta-consult`)도 열려 있는데 **비어 있습니다.** 넣을 사진이 "밝은 매장에서 상담하는 장면" 이라야 합니다 — `hero-close`(뜯긴 벽 · 폐자재)를 넣어 보고 뺐습니다. 구간이 통째로 폐업으로 읽힙니다 |
| **히어로 손글씨 · 신뢰 아이콘 줄** | 시안의 손글씨는 사진 안에 글자를 합성하는 것이라 안 넣었습니다 (폭마다 대비가 달라지고 읽어 주는 프로그램이 못 읽습니다) |
| **폰에서 카드 아이콘이 안 보입니다** | 2026-10-19 모바일 시안이 카드를 가로로 눕히며 숨긴 것입니다 (의도) — 되살리면 폰 카드가 그만큼 길어집니다 |
| **이용 방법이 넷이 아니라 다섯** | 시안에는 넷이 보이는데 `checkSteps()` 가 **다섯**을 셉니다. 줄이면 "계약 · 진행" 이 빠집니다 — 줄이시려면 그 검사도 같이 고쳐야 합니다 |
| **사업자 정보 여덟 칸 · 환경변수 · 마이그레이션 0008~0019** | 디자인과 무관하고 **사장님 쪽 일**입니다 (앞 보고서 그대로) |

⚠️ 시안의 **"검증된 업체"** 같은 말은 안 썼습니다 — 검증 기능이
없어 적는 순간 표시 · 광고의 공정화에 관한 법률 제3조입니다. 업체 ·
후기 · 실적 · 매물도 **0 인 그대로**입니다 (§3 · 절대 규칙 1).
