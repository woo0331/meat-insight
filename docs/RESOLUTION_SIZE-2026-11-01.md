색 · 글 · 구간 차례 · 기능 · 주소 · DB 는 **한 줄도 안 건드렸습니다.**

맨 뒤 블록 하나입니다.

재고 시작했습니다. 찍은 그림만 보면 "좀 어긋나네" 인 것들이라
숫자로 먼저 잡았습니다.

| | 무엇 | 재 본 값 |
|---|---|---|
| A | **기둥이 하나가 아니었습니다** | 1920px 메인에서 헤더 메뉴 240 · 로고 280 · 본문 320 · 푸터 360 — **네 자리**. `/sell` 은 280/280/280 이라 메인만 또 달랐습니다 |
| B | **헤더 오른쪽이 기둥 끝에 안 닿았습니다** | 1440px 에서 신청 단추 오른쪽 끝 **1142**, 기둥 끝 1360 — 오른쪽에 298px 이 비어 있었습니다 |
| C | **폰에서 h1 이 h2 보다 작았습니다** | 390px h1 **21.8** < h2 **25**. 구간 머리말도 두 벌(PC 34/30 · 폰 25/19) |

문서 둘(`/terms` · `/privacy`)이 폰에서 글자가 화면 끝에 붙어
있었습니다.

## 고친 것

### ① 기둥 하나 — `--w-wide` 1440 → 1360 · `html.ivh{--w}` 걷어내기

```
헤더 .w-wide  --w-wide 1440  →  1360     (본문과 같은 1280 기둥)
본문 .w       --w     1360   →  그대로
메인만        html.ivh{--w:1280px}  →  걷어냄
메뉴 글자     .gnb 의 좌우 여백에서 12px 을 덜어 기둥에 맞춤
헤더 오른쪽   .hd-r{ margin-left:auto }
```

⚠️ 바로 위 주석이 *"머리 · 꼬리도 메인에서는 같이 1200"* 이라고
적고 있었는데 **그 줄이 거짓이었습니다** — 헤더는 `.w` 가 아니라
`.w-wide` 를 씁니다.

재 본 값 — 로고 · 히어로 h1 · 신뢰띠 · 서비스 격자 · 푸터가
**여섯 폭 전부에서 같은 왼쪽 · 오른쪽 끝**입니다.

| 폭 | 1920 | 1440 | 1024 | 768 | 390 | 320 |
|---|---|---|---|---|---|---|
| 왼쪽 | 320 | 80 | 40 | 20 | 20 | 20 |
| 오른쪽 | 1600 | 1360 | 984 | 748 | 370 | 300 |

### ② 글자 한 벌

```
h1  clamp(29px, 3.9vw, 48px)     320/390 29 · 768 30 · 1024 39.9 · 1280 48
h2  clamp(23px, 2.7vw, 34px)     320/390 23 · 768 23 · 1024 27.6 · 1280 34
```

⚠️⚠️ 폰의 h1 이 작았던 까닭은 **특정도**입니다 —
`@media (max-width:760px){ .pwh h1 }`(0,1,1)가
`html.ivh #view .pwh h1`(1,1,3)에게 **져서** 죽어 있었습니다.
⚠️ h1 하한을 29 밑으로 내리면 h2 와 다시 뒤집힙니다.

구간 머리말은 가운데(`.pw-hd`)와 왼쪽(`.pw-hd-l`)이 **한 벌**입니다.

### ③ 구간 여백 한 벌 — `.pww,.pws,.pwst,.pwt{ padding:var(--sec-y) 0 }`

다섯 구간이 전부 **96px(PC) / 64px(폰)** 입니다.

### ④ 카드가 안 튀게 — 6열을 1024px 까지

```
전   1280 188×166  →  1100 331×235 (1.76배)
후   1280 188×166  →  1100 158×110  →  1024 146×104  →  768 233×167
```

⚠️⚠️ **4열을 쓰지 마세요** — 카드가 여섯이라 4 + 2 로 둘째 줄에
둘만 남습니다 (해 보고 물렀습니다). 여섯은 6 · 3 · 2 열뿐입니다.
⚠️ `grid-auto-rows:1fr` 로 두 줄의 높이를 맞췄습니다 — 320px 에서
제목이 두 줄인 카드 때문에 여섯의 높이가 제각각이었습니다.

### ⑤ 그림을 원본보다 크게 그리지 않습니다

```
.pwsv-c.has-ph .pwsv-i{ width:min(100%, 188px); margin-inline:auto; }
.pwh-art > .pwh-ph{ max-width:min(100%, 414px); }   아이폰 원본 폭
.pwh-ph2 .pwh-ph{  max-width:min(100%, 449px); }    갤럭시 원본 폭
```

재 본 배율(**파일 픽셀폭 ÷ CSS 칸폭**) —

| 폭 | 전 | 후 |
|---|---|---|
| 1920 · 1440 | 히어로 **1.03** · 서비스 1.72 | 히어로 **1.00** · 서비스 1.72 |
| 1100 | 서비스 **0.97** ⚠️ 원본보다 큼 | 서비스 **2.02** |
| 1024 | 서비스 1.06 | 서비스 **2.20** |
| 768 | 서비스 **1.38** | 서비스 **1.70** |
| 390 | 2.79 ~ 3.75 | 그대로 |

⚠️⚠️ **`naturalWidth` 로 재지 마세요.** `srcset` 에 `w` 를 쓰면
그 값이 `sizes` 로 나눈 **밀도 보정값**을 돌려줘서, `sizes` 만
고쳐도 숫자가 따라 움직입니다 — **파일의 실제 픽셀 폭**으로 재야
합니다 (처음에 그렇게 재서 "전부 1배" 라는 틀린 답을 얻었습니다).

⚠️⚠️ **카드 바탕과 그림 바탕이 같은 `#FDF6ED` 라서** 그림을 가운데에
놓아도 이음매가 안 보입니다. 바탕색을 바꾸시면 이 상한도 같이
보세요 (`img/raw/svc-*.png` 를 다시 뽑으셔야 합니다).

### ⑥ `.w` 여백이 지워진 자리 넷

```
.pwh-in, .pwc-in, .lgp{ padding-inline:var(--pad); }
.pwh-tr-g{ max-width:calc(var(--w) - var(--pad)*2); margin-inline:auto; }
```

⚠️ **줄임꼴(`padding:`)로 고치지 마세요** — 위아래 값을 건드리지
않고 좌우만 되돌리려면 `padding-inline` 입니다.

## ⚠️ 더 또렷하게 하려면 — **더 큰 원본이 필요합니다**

| 그림 | 원본 | PC 에서 그려지는 크기 | 배율 |
|---|---|---|---|
| 히어로 아이폰 | **414×482** | 414 | **1.00배** |
| 히어로 갤럭시 | 449×502 | 378 | 1.19배 |
| 서비스 여섯 | **320×156** | 188 | 1.70배 |

**2배(레티나)로 내려면 히어로는 828px, 서비스는 376px 짜리 원본이
있어야 합니다.** 지금 자산이 그보다 작아서 여기까지입니다 — 늘리는
것은 규격을 맞춘 것이 아니라 **뿌옇게 만드는 것**입니다 (이 저장소가
`fit-photos.js` 에 "원본보다 키우지 않습니다" 로 못박아 둔 규칙).

⚠️ 더 큰 파일을 주시면 **코드를 한 줄도 안 고치고** 또렷해집니다 —
상한이 `min(100%, …)` 이라 큰 쪽이 들어오면 그대로 올라갑니다.
