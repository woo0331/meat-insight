## 1. 이 사이트가 무엇인가

**창업 · 폐업 전문 버티컬 플랫폼**입니다. 주소는 `https://storeway.co.kr`
이고 화면에 보이는 이름은 **인수인계** 하나입니다.

> 창업에 필요한 모든 것. 폐업에 필요한 모든 것.

대한민국에서 사업을 시작하거나 정리하려는 사장님이 **업체 · 전문가 ·
서비스 · 점포 · 시설 · 장비 · 프랜차이즈 · 정보 · 지원사업 · 자산**을
한곳에서 `찾고 → 비교하고 → 상담하고 → 견적받고 → 연결되는` 곳입니다.

⚠️ 저희가 직접 인테리어 · 철거 · 세무 · 마케팅을 하지 않습니다 —
**통신판매중개자**입니다 (전자상거래법 제20조 제1항).

**네 기둥** — 창업 준비 / 매장 운영 / 매장 양도양수 / 폐업 · 정리.

## 2. 기술 구성

| 무엇 | 어떻게 |
|---|---|
| 프론트 | **빌드 도구 없는 정적 HTML/CSS/JS** (프레임워크 0 · npm 의존성 0). `index.html` 을 그냥 열면 돕니다 |
| 라우팅 | 해시가 아니라 **진짜 경로**. `build-pages.js` 가 주소마다 HTML 파일을 미리 만듭니다 |
| 백엔드 | **Vercel 서버리스 함수** 12개 (`api/*.js`) |
| DB | **Supabase Postgres** (서울 ap-northeast-2) · 마이그레이션 번호제 |
| 배포 | **Vercel** — `main` 에 올리면 곧바로 배포됩니다 |
| 데이터 | `js/data/*.js` **33개** — 전부 스크립트 안에 들어 있고 `fetch` 가 아닙니다 |
| 화면 | `js/pages/*.js` **13개** |
| 검사 | **열여덟 묶음** + 빌드 가드 **42개** (`node tools/ship.js`) |

### 왜 프레임워크가 없는가

의도적입니다. 데이터가 `fetch` 가 아니라 스크립트 안에 있어서
**"로딩 중" 이라는 순간이 없습니다** — 그래서 스켈레톤(로딩 뼈대)을
만들 필요도, 만들어서도 안 됩니다. 크롤러 본문도 빌드가 미리 그려 넣어서
자바스크립트 없이도 같은 내용이 보입니다.

## 4. 데이터베이스

마이그레이션 **0001 ~ 0016** (+ 되돌리기 1개). 표 **17개** · 함수 **36개**.

```
request ─┬─ request_item     신청 하나에 서비스 여러 개
         ├─ assignment        배정 (= 제3자 제공 · 동의 시각 필수)
         ├─ quote             업체가 낸 견적 (고객이 고름)
         ├─ request_photo     사진 · 서류 (비공개 버킷)
         └─ deal              계약 · 수수료 · 정산
provider ─┬─ provider_contact 담당자 (⚠️ 손님 정책 없음)
          └─ fee_policy       수수료 정책 (계약에 사본으로 박힘)
provider_apply   업체 입점 신청 (아직 업체가 아님)
account · audit_log · settlement · user_state · offer · schema_version · deal_move
```

### 지키는 규칙 넷

1. **GRANT 와 RLS 는 다른 자물쇠입니다.** 표에는 `select` 만 주고, 쓰는 것은
   전부 `security definer` **문(함수)** 으로만 — 그래야 **기록 없이 지나갈
   길이 없습니다.**
2. **돈이 걸린 상태로는 관리자만** 들어갑니다. 계약 완료에서 정산으로 **바로
   가는 길이 없습니다** (업체가 "계약했습니다" 해도 수수료가 자동 확정되지
   않습니다).
3. **감사 기록에 개인정보를 안 싣습니다.** 기록은 고칠 수도 지울 수도 없어서
   거기 성함·번호를 박으면 그 자체가 또 하나의 보관입니다.
4. **화면의 key 와 DB 의 enum 이 어긋나면 빌드가 멈춥니다**
   (`checkDealSql()` 등이 하나씩 맞춰 봅니다).

### 개인정보 쪽

- **배정이 곧 제3자 제공**입니다 (개인정보보호법 제17조 제2항) — 접수 때
  뭉뚱그려 받지 않고, 업체가 정해지면 **상호를 알리고 그때 다시** 받습니다.
  동의 시각이 없으면 DB 가 배정을 거절합니다.
- 관리자 목록에 **성함 · 연락처가 없습니다.** 한 건을 열 때만 주고 **열람
  이력이 남습니다** (제29조).
- 환경변수를 넣는 순간 그 회사(Slack · Resend 등)가 수탁자가 되므로
  **방침의 수탁자 목록을 같은 날 고칩니다** (제26조).

### P1-6 유지 수수료 모델 (`0015_retain_fee.sql`)

제휴 논의 중인 회사의 수익 구조가 "매달 요금의 일정 비율 + 해지 방어 성과"
인데, 그걸 담을 칸이 없었습니다 (회차마다 **정액**뿐이라 월 5만원 집과
15만원 집이 같아졌습니다). 수익모델이 **6 → 8** 이 됐습니다.

```
mrr_rate  월 요금의 일정 비율 × 회차
retain    유지 · 해지 방어 성과 정액
kept      확정 조건 — 약정 유지 확인 후
```

⚠️ **한 달치를 먼저 반올림하고 회차를 곱합니다** — 합계에 곱해서 한 번만
반올림하면 청구서에 **달마다 적는 금액의 합과 총액이 어긋납니다.**
⚠️ 월 1,000원 · 0.0001% 처럼 한 달치가 0원으로 떨어지면 **0원을 내놓지 않고
거절합니다.**

### P1-7 업체 입점 신청을 DB 에 저장 (`0016_provider_apply.sql`)

`/join` 신청이 **Slack 글로만** 남았습니다. 채널 글이 묻히면 그 업체는
사라지고, 직원은 전화하려고 업체명 · 번호 · 하는 일을 **다시 손으로** 칩니다.
지금은 표에 저장되고 접수번호가 나오고 `/admin` 에 목록이 섭니다
(상태 넷: 새 신청 · 통화함 · 등록 완료 · 진행 안 함).

⚠️⚠️ **`provider` 표에 바로 넣지 않습니다.** 신청은 아직 업체가 아닙니다 —
통화도 안 해 봤고 계약도 없습니다. 꽂으면 배정 고르개에 바로 떠서, 거기
배정되면 **아무 합의도 없는 회사로 손님 성함·연락처가 넘어갑니다**
(제17조 제2항).
⚠️ 손님 · 업체에게는 **한 줄도 안 보입니다** (RLS 에 그 정책이 아예 없습니다).

## 9. 이 프로젝트에서 **절대 하면 안 되는 것** (다른 AI 에게 꼭 전해 주세요)

1. **업체 · 브랜드 · 매물 · 후기 · 숫자를 지어내지 않습니다.** 지금 0 이고
   화면은 0 이라고 말합니다. 샘플 카드를 채우면 그 순간 법 위반입니다.
2. **값이 없는 항목은 자리표시자를 찍지 말고 줄째 뺍니다.** `(미기재)` ·
   `undefined` · "이미지 준비 중" · "준비 중" 금지.
3. **운영자에게 할 말을 손님 화면에 찍지 않습니다.** 무엇을 설정해야
   하는지는 `console.warn` 으로.
4. **사용자가 쓴 글은 반드시 `esc()`** 를 통과시킵니다.
5. **하지 않은 일을 했다고 말하지 않습니다.** "AI 가 분석했습니다" ·
   "몇 시간 안에 연락드립니다" · 작동하지 않는 버튼 금지.
6. **브랜드 이름과 조사를 손으로 적지 않습니다.** 이름이 **여섯 번**
   바뀌었고 `js/data/brand.js` 한 곳에만 있습니다. 조사는 `koWith()` 가
   고릅니다 ("인수인계은" 사고가 **푸터 전체**에 나간 적이 있습니다).
7. **밝은 사이트입니다** (BRIGHT PREMIUM). 어두운 면이 15% 를 넘으면 검사가
   막습니다. 창업=블루 · 폐업=오렌지이고 **폐업을 빨강으로 넘기지 않습니다**
   ("폐업은 나쁜 것" 이라는 말이 됩니다).
8. **같은 규칙을 두 곳에 적지 않습니다.** 화면과 DB · 데이터와 화면이 어긋나면
   빌드가 멈추게 해 두었습니다.
9. **검사를 느슨하게 만들어 통과시키지 않습니다.** 사람이 확인하는 자리를
   검사로 바꿔 둔 것이라, 느슨하게 만들면 아무도 안 보는 것이 나갑니다.
10. **주석에 백틱을 쓰지 않습니다.** 검사 본문이 템플릿 문자열이라 거기서
    끊겨 **검사가 통째로 안 돕니다** — 이 저장소에서 **스물여섯 번** 겪었습니다.
