## 2. 그림을 어떻게 뽑았나 (§3)

1. 시안을 재서 카드 여섯의 자리를 찾았습니다 — `y198~473`, 일러스트
   `216~345`, 빈 띠 `346~361`, 제목 `362~389`.
2. **`y198~354`** 에서 잘랐습니다. 제목보다 **8px 위**라 글자 ·
   화살표가 한 점도 안 들어갑니다 (§3-2 · §3-5).
3. 시안 카드의 폭이 **302~331 로 제각각**이고 그림은 어느 카드에서나
   **폭의 87%** 였습니다. 그래서 폭을 **320 에 맞춰** (배율 0.97~1.06)
   여섯의 결을 맞췄습니다 — 그래야 §6 의 "이미지 크기가 일정한지 ·
   카드 높이가 동일한지" 가 성립합니다.
4. 바탕은 **지우지 않고 카드 색 `#FDF6ED` 로 눌렀습니다.** 알파로
   뚫어 보니 원본이 손실 압축이라 **흰 바탕에서 베이지 네모**가
   남았습니다 (찍어 보고 알았습니다). 지금은 그림 바탕과 카드 바탕의
   차이가 **0** 이라 이음매가 안 보입니다.
5. 파일은 **자리 이름**으로 저장했습니다 (§3 "기존 프로젝트의 이미지
   경로 규칙") — `WOW_PHOTO_SLOTS` 에 규격이, `WOW_PHOTOS` 에 주소와
   `alt` 가 들어 있고 `photoBox()` 가 `<picture>` 로 냅니다.

```
img/svc-sell.webp    8KB      img/svc-sell.jpg    12KB    320×156
img/svc-buy.webp     8KB      img/svc-buy.jpg     11KB
img/svc-repair.webp  9KB      img/svc-repair.jpg  14KB
img/svc-b2b.webp     8KB      img/svc-b2b.jpg     12KB
img/svc-corp.webp   10KB      img/svc-corp.jpg    13KB
img/svc-export.webp  9KB      img/svc-export.jpg  13KB
```

## 4. 카드 클릭 (§5)

여섯을 실제로 눌러 도착 화면과 제목을 확인했습니다. 전부 **원래부터
있던 화면**이고 새로 만든 것이 없습니다 (§5 "없는 페이지를 임의로
정상 작동하는 것처럼 만들지 않는다").

```
내 폰 판매      → /sell          내 폰 팔기
중고폰 구매     → /shop          내 폰 구매
수리 서비스     → /repair        수리 서비스
B2B 도매·경매   → /bid           최고가 경쟁입찰
기업 대량 매입  → /biz?t=corp    기업 대량 매입
해외 수출       → /biz?t=export  해외 수출
```

h1 은 어느 화면에서나 하나이고 JS 에러가 없습니다.

## 6. 남은 한 가지 — **더 큰 원본**

시안에서 뽑을 수 있는 그림이 **320px 폭**뿐입니다.

```
PC 186px 칸   1.7배   또렷합니다
태블릿 303px   1.06배  레티나에서 조금 무릅니다
```

늘리면 규격을 맞춘 것이 아니라 뿌옇게 만드는 것이라 **안 늘렸습니다.**
더 또렷하게 하시려면 **일러스트 여섯을 각각 큰 파일로** 주세요 —
`img/raw/svc-<이름>.png` 에 같은 이름으로 넣고
`node tools/fit-photos.js` 한 번이면 **코드를 한 줄도 안 고치고**
바뀝니다 (권장 800×390 이상 · 바탕은 `#FDF6ED` 또는 투명).

## 7. ⚠️ `img/raw/` 는 저장소에 안 올라갑니다

`.gitignore` 에 들어 있습니다 (원본을 공개 저장소에 올리지 않기 위해서
오래전부터 그렇습니다). 그래서 **잘라 낸 원본 여섯은 이 작업 환경에만**
있고, 다음 차수가 카드 바탕색을 바꾸거나 더 큰 판으로 다시 뽑으려면
**확정 시안 이미지를 다시 주셔야 합니다.**
