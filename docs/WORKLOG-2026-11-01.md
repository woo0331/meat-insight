
  특정도에 져서 규칙이 죽어 있었습니다

### ① 가격 칩을 누르면 **화면이 터졌습니다**

```
/shop?pr=a   TypeError: window.amInRange is not a function
             → 목록이 통째로 안 그려짐 (거르개 줄까지 사라지고 0건)
```

10-31 에 창업 · 폐업 `market.js` 를 지울 때 **그 함수가 같이
날아갔습니다** — `/shop` 가격 거르개가 부르는 **유일한 자리**입니다.
되살렸고, 경계 열 가지를 넣어 재서 **전부 한 칸**에만 걸리는 것과
다섯 칸의 합이 상품 수와 같은 것을 확인했습니다.

```
전   a 0 · b 0 · c 0 · d 0 · e 0 건  (전부 터짐)
지금 a 1 · b 2 · c 1 · d 0 · e 2 건
```

### ② 메인 브랜드 카드 넷이 **아무 칩도 안 켰습니다**

메인은 브랜드 **여섯**을 내는데 `/shop` 의 제조사 칩은 **셋**만
읽고 있었습니다 — 구글 · 화웨이 · OPPO · 샤오미 카드를 누르면
거르개는 걸리는데(카드 0장) **손님은 자기가 거른 줄 모릅니다.**

`amShopMakers()` 한 곳으로 묶었고, 0건이면 **"그 조건에 맞는 기기가
없습니다 · 조건 모두 풀기"** 가 섭니다. **여섯 다 켜집니다** (폰도 같음).

⚠️ 기기 DB(`AM_MAKERS`)는 **안 늘렸습니다** — 취급 모델이 0종인 넷을
넣으면 `/sell` 에 **고를 것이 없는 제조사**가 생깁니다.

### ③ `/quote` 의 보내기 단추가 **혼자 브라운**이었습니다

```
스물한 주소를 띄워 재니
  /quote   rgb(128,96,71)  ← 창업 · 폐업 시절 색
  나머지   rgb(210,70,1)   ← PHONEWAY 오렌지
```

`/quote` 는 **사이트 전체가 흘러드는 신청 화면**이고 손님이 제일
마지막에 누르는 단추가 거기 있습니다. 같이 빠져 있던 셋도 넣었습니다 —
`/d/:id`(상품 상세 · `/shop` 카드가 전부 도착하는 자리) ·
`/terms` · `/privacy`(**스물한 화면의 푸터**에서 바로 갑니다).

지금 **스물한 화면이 한 팔레트**이고, 색이 바뀌었으니 전수 점검을
다시 돌려 **대비 · 구간 색차 · 어두운 면 전부 통과**했습니다.
