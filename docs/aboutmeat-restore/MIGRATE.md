# 기존 MEAT INSIGHT 자료 처리 방침 (2026-11-17 대표자 결정 반영)

> ABOUTMEAT 은 새 사업모델로 처음부터 다시 설계합니다. 옛 사업모델 · 디자인 · 카테고리 · 표 구조는 옮기지 않습니다.

| 자료 | 처리 | 근거 |
|---|---|---|
| 커뮤니티 글 90 · 댓글 99 | **옮기지 않음** | 같은 시각에 심어 둔 예시 글로 보임 |
| 상품 14 · 매물 1 | **옮기지 않음 · 공개 안 함** | 자동 공개 금지. 테스트 사이트도 옛 DB 를 읽지 않음 |
| 상담 4 · 구매 2 · 파트너 1 · 공급 1 · 공급사 1 (개인정보) | **옮기지 않음** | 보유 목적과 이전 근거 확인 전까지 |
| 나머지 7개 표 | 0줄 · 해당 없음 | |
| 옛 관리자 비밀번호 | **어디에도 재사용 금지** | 공개 저장소 이력에 남아 있음 |

- 옛 자료는 지우지 않고 공용 Supabase 프로젝트에 그대로 둡니다. A안(`rls-minimal.sql`)을 실행하면
  공개 키로는 읽기 · 쓰기 · 지우기가 모두 막히고, 대표자는 Dashboard 에서 계속 볼 수 있습니다.
- 개인정보 줄의 처리(보관 · 이전 · 파기)는 대표자가 보유 목적을 확인한 뒤 따로 정합니다.
  파기하게 되면 파기 일자 · 항목을 기록하고, 삭제는 별도 승인 후에만 합니다.
- 새 Supabase 프로젝트에는 `new-project-baseline.sql`(기본 권한 잠금)만 먼저 넣고, 표는 새 설계가 확정된 뒤 만듭니다.
