## 2. 시안과 **다르게** 한 것 — 까닭

⚠️ 두 묶음으로 갈라 적습니다 — **① 시안 재현을 위해 고쳐야 하는 차이**(고칠 수 있고, 고치면 시안에 더 가까워집니다)와 **② 기존 기능 · 규칙 보존 때문에 필요한 차이**(고치면 지금 도는 것이 깨지거나 지어낸 것을 적게 됩니다).

| | 항목 | 어느 묶음 |
|---|---|---|
| ⓑ | ~~탭 줄이 왼쪽 칸 안에 있음~~ | **① 고쳤습니다** (2026-11-12) — PC 왼쪽 기둥으로 세웠습니다 |
| ⓐ | 탭이 열셋 | ② 보존 (게시판 키 · URL) |
| ⓒ | 인기글 · 랭킹 없음 | ② 보존 (세어 본 적이 없습니다) |
| ⓓ | 시안의 예시 글을 안 베낌 | ② 보존 (가짜 데이터 금지) |
| ⓔ | 레일을 빌드가 찍음 | ② 보존 — **보이는 것은 시안과 같습니다** |
| ⓕ | 빈 화면에 0건을 밝힘 | ② 보존 (절대 규칙 1 · 2) |
| ⓖ | 폰 바닥 탭에 「채팅」 없음 | ② 보존 (그 기능이 없습니다) |


### ⓐ 탭이 여섯이 아니라 **열셋**입니다
시안의 탭은 여섯이지만 확정 지시 ⑩ 이 「기존 게시판 분류와 URL 연결을
보존」하라고 적었습니다. 지금 게시판은 열둘(+「게시판 모아보기」)이고
그 키가 `cq.cat` 에 **글자로 저장**되어 있습니다. 여섯으로 줄이면 나머지
게시판에 이미 올라온 글이 갈 자리가 없어집니다.
→ **수를 줄이지 않고 줄바꿈**으로 담습니다(`flex-wrap`). 칸 수를 안 박았으므로
게시판이 늘어도 마지막 줄에 구멍이 안 생깁니다.

### ⓑ → **고쳤습니다** — PC 왼쪽 게시판 기둥 (2026-11-12)

시안대로 **PC 에서 왼쪽에 게시판 메뉴**가 섬니다
(게시판 모아보기 · 전체 글 + 게시판 열둘 = **칸 열넷**).
세 기둥입니다 — 왼쪽 200px · 가운데 글 · 오른쪽 280px 안내.
1,100px 아래에서는 알약 줄로 되돌아가 글 위에 섭니다.

⚠️⚠️⚠️ **기존 탭 이벤트 구조를 정리해야 했습니다.** 전에는 `bind()` 가
`#cqlist` **안에서만** `[data-bd]` 를 집었습니다. 메뉴만 밖으로 빼고
그대로 두었으면 **탭이 조용히 안 눌립니다**(에러 0줄 · 모양은 멀쩡합니다).
지금은 `.cqw` 한 곳에서 거품으로 올라오는 눌림을 **한 번만** 묶습니다
(`bindNav()`) — 다시 그릴 때마다 묶으면 한 번 눌렀는데 호출이 여러 번 돕니다.

⚠️ **게시판 열둘과 `?s=` 주소는 하나도 안 바꿨습니다.**
⚠️ 메뉴를 **빌드가 링크로** 찍습니다 — 자바스크립트가 꺼져도 눌리고,
크롤러도 게시판 열둘을 봅니다. 화면은 **켜진 칸만** 갈아 끼웁니다.

### ⓒ 「인기글 · 랭킹 · 주간 베스트」를 레일에 **안 뒀습니다**
세어 본 적이 없습니다. 조회는 **회원 조회**만 셉니다(비로그인은 IP 를 안
받아 셀 수가 없습니다 · 0059). 「인기」를 적으면 지어낸 순위입니다
(절대 규칙 1 · 0047 §2.C).

### ⓓ 시안의 글 제목 · 글쓴이 · 날짜 · 조회 수를 **안 베꼈습니다**
예시 데이터입니다. 운영에서는 0건이면 ⓕ 의 빈 화면이 나옵니다.

### ⓔ 레일을 **빌드가 찍습니다** (화면이 안 그립니다)
글자뿐이라 ① 설정(Supabase)이 없어도 ② 자바스크립트가 꺼져도 ③ 크롤러에게도
그대로 보입니다. 화면이 그리면 그 셋에서 사라집니다.
덤으로, 받은 글자를 그대로 잇는 함수(`shell(main)`)를 만들지 않게 되어
`check-safe` ⑥(esc) 이 **그 줄에서 계속 삽니다**.

### ⓕ 빈 화면 문구는 시안의 말을 쓰되 **0건이라고 밝힙니다**
「아직 작성된 글이 없습니다 / 첫 번째로 골프 이야기를 남겨보세요」 +
「…에 올라온 글이 **0건**이고, 지어낸 글을 채우지 않습니다」 +
「첫 이야기 작성」 단추(막다른 길로 두지 않습니다 · 절대 규칙 2).

### ⓖ 폰 바닥 탭에 「채팅」이 **없습니다**
그 기능이 없습니다(절대 규칙 5). 시안 ⑩ 에도 없습니다.
넷은 전부 실제 주소입니다 — 홈 `/` · 검색 `/search` · 글쓰기 `#cqbox` ·
내정보 `/my`. 「글쓰기」가 가는 `#cqbox` 는 **설정이 없어도 안내 글이 있어**
눌러도 아무 일이 안 나는 칸이 아닙니다(`#lsbox` 에서 겪은 자리).

## 3. 네 가지 상태를 갈라서 냅니다 (확정 지시 §4)

| 상태 | 화면 | 상자 |
|---|---|---|
| 로딩 | 「불러오는 중입니다…」 | `.cqz` |
| 정상 | 글 카드 목록 + 쪽 넘김 | `.cql` |
| **빈 목록** | 「아직 작성된 글이 없습니다 … **0건**」 + 「첫 이야기 작성」 | `.cqnone` |
| **조회 실패** | 「지금 글목록을 불러오지 못했습니다 · **글이 없다는 뜻이 아닙니다**」 + **「다시 시도」** + 「고객센터」 | `.cqfail` |

⚠️⚠️⚠️ **2026-11-12 에 고친 고장입니다.** `get()` 이 실패를 전부 삼켜
`{rows:[]}` 로 돌려주고 있었습니다. 그래서 그물이 끊기거나 질의가
거절되면(예 — **0075 가 운영 DB 에 없을 때**) 화면이 **「아직 작성된
글이 없습니다 · 첫 이야기를 남겨보세요」**를 적었습니다. 세어 본 것처럼
말하는 것이라 절대 규칙 1 이고, 글이 있는데 못 본 분께 **글을 또 쓰라고**
하는 꼴이었습니다.

- 상자도 · 색도 · 말도 **다릅니다**(`.cqnone` 은 초록 쪽 · `.cqfail` 은 경고 쪽)
- **다시 시도**를 누르면 실제로 다시 부릅니다 — 보고 있던 게시판 · 쪽 ·
  찾는 말이 그대로 살아 있습니다(주소에서 읽습니다)
- 모아보기에서는 **그 게시판 칸에만** 적습니다. 열둘이 **전부** 실패하면
  그때만 큰 상자 하나입니다
- 글 상세도 갈라 둡니다 — 전에는 못 읽은 것을 **「내려갔거나 운영자가
  가린 글일 수 있습니다」**로 단정했습니다
- **설정 이름(SUPABASE…)은 손님 화면에 한 글자도 안 적습니다**(절대 규칙 3)

⚠️ 검사 여섯 건이 이 자리를 지킵니다 — 500 을 꽂아 놓고 ① 실패 상자가
서는가 ② 「없습니다」를 **안 적는가** ③ 다시 시도 단추가 있는가
④ 설정 이름이 없는가 ⑤ 눌렀을 때 **실제로 다시 불러오는가**.

## 5. 검사 통과 여부 — **배포 가능 여부와 갈라서**

「전부 초록」이라고 적지 않습니다.

### 5-2. 배포 가능 여부 (손님에게 내보내도 되는가) — **아직 아닙니다**
| 막는 것 | 누가 |
