## 2. 시안과 **다르게** 한 것 — 까닭

⚠️ 두 묶음으로 갈라 적습니다 — **① 시안 재현을 위해 고쳐야 하는 차이**(고칠 수 있고, 고치면 시안에 더 가까워집니다)와 **② 기존 기능 · 규칙 보존 때문에 필요한 차이**(고치면 지금 도는 것이 깨지거나 지어낸 것을 적게 됩니다).

| | 항목 | 어느 묶음 |
|---|---|---|
| ⓑ | 탭 줄이 왼쪽 칸 안에 있음 | **① 고쳐야 하는 차이** — 대표 승인하시면 고칩니다 |
| ⓐ | 탭이 열셋 | ② 보존 (게시판 키 · URL) |
| ⓒ | 인기글 · 랭킹 없음 | ② 보존 (세어 본 적이 없습니다) |
| ⓓ | 시안의 예시 글을 안 베낌 | ② 보존 (가짜 데이터 금지) |
| ⓔ | 레일을 빌드가 찍음 | ② 보존 — **보이는 것은 시안과 같습니다** |
| ⓕ | 빈 화면에 0건을 밝힘 | ② 보존 (절대 규칙 1 · 2) |
| ⓖ | 폰 바닥 탭에 「채팅」 없음 | ② 보존 (그 기능이 없습니다) |


### ⓐ 탭이 여섯이 아니라 **열셋**입니다
시안의 탭은 여섯이지만 확정 지시 ⑩ 이 「기존 게시판 분류와 URL 연결을
보존」하라고 적었습니다. 지금 게시판은 열둘(+「게시판 모아보기」)이고
그 키가 `cq.cat` 에 **글자로 저장**되어 있습니다. 여섯으로 줄이면 나머지
게시판에 이미 올라온 글이 갈 자리가 없어집니다.
→ **수를 줄이지 않고 줄바꿈**으로 담습니다(`flex-wrap`). 칸 수를 안 박았으므로
게시판이 늘어도 마지막 줄에 구멍이 안 생깁니다.

### ⓑ 탭 줄이 **왼쪽 칸 안**에 있습니다 (시안은 폭 전체로 읽힙니다)
탭을 그리는 자리와 눌림을 받는 자리가 `#cqlist` **한 곳**입니다
(`bind()` 가 그 안에서만 집습니다). 탭만 바깥으로 빼면 집는 자리가 둘이
되고, 한쪽만 고치는 날 탭이 조용히 안 눌립니다.
→ 폭이 1,140px 라 열셋이 **두 줄**로 들어갑니다. 바꾸시겠다면 `#cqbar` 를
따로 내고 `bind()` 의 뿌리를 같이 올리는 일이 됩니다 — 말씀 주시면 합니다.

### ⓒ 「인기글 · 랭킹 · 주간 베스트」를 레일에 **안 뒀습니다**
세어 본 적이 없습니다. 조회는 **회원 조회**만 셉니다(비로그인은 IP 를 안
받아 셀 수가 없습니다 · 0059). 「인기」를 적으면 지어낸 순위입니다
(절대 규칙 1 · 0047 §2.C).

### ⓓ 시안의 글 제목 · 글쓴이 · 날짜 · 조회 수를 **안 베꼈습니다**
예시 데이터입니다. 운영에서는 0건이면 ⓕ 의 빈 화면이 나옵니다.

### ⓔ 레일을 **빌드가 찍습니다** (화면이 안 그립니다)
글자뿐이라 ① 설정(Supabase)이 없어도 ② 자바스크립트가 꺼져도 ③ 크롤러에게도
그대로 보입니다. 화면이 그리면 그 셋에서 사라집니다.
덤으로, 받은 글자를 그대로 잇는 함수(`shell(main)`)를 만들지 않게 되어
`check-safe` ⑥(esc) 이 **그 줄에서 계속 삽니다**.

### ⓕ 빈 화면 문구는 시안의 말을 쓰되 **0건이라고 밝힙니다**
「아직 작성된 글이 없습니다 / 첫 번째로 골프 이야기를 남겨보세요」 +
「…에 올라온 글이 **0건**이고, 지어낸 글을 채우지 않습니다」 +
「첫 이야기 작성」 단추(막다른 길로 두지 않습니다 · 절대 규칙 2).

### ⓖ 폰 바닥 탭에 「채팅」이 **없습니다**
그 기능이 없습니다(절대 규칙 5). 시안 ⑩ 에도 없습니다.
넷은 전부 실제 주소입니다 — 홈 `/` · 검색 `/search` · 글쓰기 `#cqbox` ·
내정보 `/my`. 「글쓰기」가 가는 `#cqbox` 는 **설정이 없어도 안내 글이 있어**
눌러도 아무 일이 안 나는 칸이 아닙니다(`#lsbox` 에서 겪은 자리).

## 3. 네 가지 상태를 갈라서 냅니다 (확정 지시 §4)

| 상태 | 화면 |
|---|---|
| 로딩 | 「불러오는 중입니다…」 |
| 정상 | 글 카드 목록 + 쪽 넘김(「앞쪽 · N쪽 · 다음 쪽」 — 전체 쪽 수는 **안 적습니다**) |
| 빈 목록 | ⓕ 의 빈 화면. **찾는 말이 있을 때는 다른 말**(「찾으시는 글이 없습니다」) |
| 조회 실패 | 「0건이라는 뜻이 아닙니다」를 그 자리에서 밝힙니다 |
