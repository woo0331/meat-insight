# 카카오 로그인 — 사장님이 누르실 것 (1단계)

> 2026-11-11 · 작성: 작업 세션
> ⚠️ 이 글은 **제가 못 보는 화면**을 사장님이 대신 보시는 글입니다.
> 그래서 **「보시고 알려 주세요」로 시작**합니다 — 제가 모르는 것을
> 안다고 적으면 사장님이 헛걸음하십니다.

---

## 0. 한 줄로

> **Supabase 가 카카오에 보내는 동의항목 셋은 우리가 못 고칩니다.**
> 카카오 앱에서 **그 셋을 다 켜거나**, 아니면 **다른 방식으로 연결**해야 합니다.

### 그걸 어떻게 아는가 — 증거

사장님 쪽에서 받아 주신 **실제 카카오 인가 요청**이 이것이었습니다.

```
account_email   profile_image   profile_nickname   profile_nickname
```

`profile_nickname` 이 **두 번**입니다.

- 하나는 **Supabase(GoTrue)의 카카오 기본값**
  (`account_email` + `profile_image` + `profile_nickname` — 늘 이 셋을 보냅니다)
- 하나는 **우리가 보낸 것**

즉 우리가 보낸 값이 기본값을 **덮지 않고 뒤에 붙습니다.**
→ **사이트 코드로는 `account_email` 을 뺄 수 없습니다.**

그래서 우리 쪽에서 보내던 줄은 **뗐습니다**(중복만 만들었습니다).
지금 사이트는 `?provider=kakao&redirect_to=...` 만 보냅니다.

## 1단계 — 카카오 콘솔에서 **보기만** 하시고 알려 주세요

⚠️ **이 단계에서는 아무것도 바꾸지 마세요.** 보고 적어 오시는 것이 전부입니다.

### 가는 길

```
https://developers.kakao.com  →  로그인  →  내 애플리케이션
→  (골프올인원 앱 선택)  →  왼쪽 메뉴 「카카오 로그인」  →  「동의항목」
```

### 적어 오실 것 — **세 줄**

그 화면의 목록에서 **아래 셋**을 찾아, **각 줄의 오른쪽에 뭐라고 적혀 있는지** 그대로 알려 주세요.

| # | 찾으실 이름 | 적어 오실 것 |
|---|---|---|
| ① | **닉네임** (`profile_nickname`) | 「필수 동의」 / 「선택 동의」 / 「사용 안 함」 중 무엇인가 |
| ② | **프로필 사진** (`profile_image`) | 같음 |
| ③ | **카카오계정(이메일)** (`account_email`) | 같음 — 그리고 **설정 단추를 누를 수 있나**, 아니면 **「비즈 앱 전환 필요」 같은 안내가 뜨는가** |

### 같이 봐 주실 것 — **두 줄 더**

```
왼쪽 메뉴 「앱 설정 → 앱 키」   →  앱 이름과 「REST API 키」가 보이는지만
왼쪽 메뉴 「카카오 로그인」      →  맨 위 「활성화 설정」이 ON 인지
                               →  「OpenID Connect 활성화」가 ON 인지
                               →  「Redirect URI」에 적힌 주소
```

⚠️⚠️ **키 값 자체는 채팅에 붙여 넣지 마세요.** 「REST API 키가 보입니다」
정도면 됩니다. Redirect URI 는 주소이므로 알려 주셔도 됩니다.

## 2단계 — 1단계 답에 따라 갈립니다

### 길 A — ③ 이메일을 **켤 수 있는 경우**

가장 간단합니다. 셋을 다 **「선택 동의」**로 켜면 끝입니다.

```
동의항목 → 각 줄의 「설정」 →  「선택 동의」 선택
   ① 닉네임          → 선택 동의
   ② 프로필 사진      → 선택 동의
   ③ 카카오계정(이메일) → 선택 동의
동의 목적을 묻는 칸에는 — 「회원 식별 및 서비스 이용」 정도로 적으시면 됩니다
저장
```

⚠️ **「필수 동의」로 두지 마세요.** 필수로 두면 손님이 하나라도 거부하면
로그인 자체가 안 됩니다. **선택 동의**면 거부해도 들어옵니다.

⚠️ 저희는 **이메일을 저장하지 않습니다** — DB 에 이메일 칸이 아예 없습니다.
받아도 버립니다. 그래도 카카오가 「요청하려면 켜 두라」고 하므로 켭니다.

### 길 B — ③ 이메일에 **「비즈 앱 전환 필요」가 뜨는 경우** (아마 이쪽일 것 같습니다)

비즈 앱 전환에는 **사업자등록번호**가 필요합니다.

여기서 다시 둘로 갈립니다.

#### B-1. **사업자등록이 이미 있으시면** → 비즈 앱 전환이 가장 빠릅니다

```
내 애플리케이션 → (앱) → 「앱 설정 → 비즈니스」 → 「비즈 앱 전환」
→ 사업자등록번호 입력 → 심사
```

⚠️ **이 길은 덤이 큽니다.** 사업자등록은 **사이트 영업을 시작하는 데도
반드시 필요**합니다 — 전자상거래법 제10조가 요구하는 여덟 칸(상호 ·
대표자 · 사업자등록번호 · 통신판매업 신고번호 · 주소 · 전화 · 이메일 ·
개인정보 보호책임자)이 지금 **전부 비어 있어서**, 그게 없으면 문을 못 엽니다.
**카카오 때문이 아니라도 해야 하는 일**이고, 하시면 둘이 같이 풀립니다.

#### B-2. **사업자등록이 아직 없으시면** → Supabase 쪽으로 돌아갑니다

카카오 기본 연결을 안 쓰고, **Supabase 의 Custom Provider** 로 카카오를
직접 넣습니다. 그러면 **동의항목을 우리가 정합니다** (이메일을 안 받습니다).

그 칸이 무엇을 묻는지 제가 못 봅니다. **이것만 봐 주세요** —

```
https://supabase.com/dashboard  →  (프로젝트: igignylgzjphtnyxhhsd)
→  Authentication  →  Providers  →  목록 맨 아래
→  「Custom Providers」 또는 「+ New Provider」
```

그 칸을 누르면 **무엇을 입력하라고 하는지** 알려 주세요 (화면을 찍어
보내 주셔도 좋습니다). 보통 둘 중 하나입니다 —

| 묻는 것 | 그러면 |
|---|---|
| **Discovery URL** 하나만 | 카카오는 그 주소를 공개합니다 → **코드 0줄** |
| **Authorization URL · Token URL · User Info URL** 을 따로 | 카카오 주소 셋을 적으면 됩니다 → **코드 0줄** |
| 둘 다 아님 | 그때는 제가 서버 쪽 코드를 씁니다 (2~3일) |

## 3단계 — 바꾸신 뒤 **되는지 보는 법** (중요합니다)

> ⚠️ **이걸 안 하면 「고쳤다」를 아무도 증명 못 합니다.**
> 저는 사이트에 못 나가므로, 이 확인은 사장님만 하실 수 있습니다.

### 가장 쉬운 길 — 오류가 나면 **주소창을 복사**

1. `https://storeway.co.kr/login` 을 엽니다
2. **카카오 로그인**을 누릅니다
3. **KOE205 화면이 뜨면** — 그 화면의 **주소창을 통째로 복사**해서 보내 주세요
   (`kauth.kakao.com/oauth/authorize?...scope=...` 가 들어 있습니다)
4. **로그인이 되면** — 됐습니다. 아래 「되고 나서 볼 것」으로 갑니다

### 더 확실한 길 — 크롬 개발자 도구

```
F12  →  「Network」 탭  →  「Preserve log」 체크
→  카카오 로그인 클릭
→  목록에서 kauth.kakao.com 으로 가는 줄을 찾아 클릭
→  Headers 의 Request URL 을 복사
```

그 주소의 `scope=` 뒤에 무엇이 들어 있는지가 **답**입니다.

### 되고 나서 볼 것 — 이것까지 봐야 「완료」입니다

| # | 볼 것 | 어떻게 |
|---|---|---|
| 1 | 로그인 뒤 **원래 보던 화면**으로 돌아오는가 | 눈으로 |
| 2 | **새로고침해도** 로그인이 유지되는가 | F5 |
| 3 | 다른 화면으로 가도 유지되는가 | 메뉴 눌러 보기 |
| 4 | **로그아웃**이 되는가 | 머리말에서 |
| 5 | 두 번째 로그인 때 **계정이 또 생기지 않는가** | Supabase → Authentication → Users 에서 줄 수 |
| 6 | 그 카카오 계정이 **관리자가 아닌가** | `/admin` 에 들어가지면 안 됩니다 |
| 7 | **기존 이메일 로그인이 그대로 되는가** | `/login` 에서 메일 주소로 |

## ⚠️ 꼭 지켜 주실 것

| | |
|---|---|
| **키를 채팅에 붙여 넣지 마세요** | REST API 키 · Client Secret 은 **Supabase 칸에 직접** 넣으십니다. 저는 안 받습니다 |
| **기존 이메일 로그인 칸을 지우지 마세요** | 카카오가 **완전히** 될 때까지 |
| **관리자 계정을 손대지 마세요** | 지우거나 다시 만들지 않습니다 |
| **카카오로 들어온 계정에 관리자를 주지 마세요** | 새로 들어온 계정은 전부 일반 회원입니다 |

### ⚠️⚠️⚠️ 그리고 가장 중요한 것

**이메일 로그인 칸을 없애기 전에 `db/README.md` 의 §1-4c 를 꼭 보세요.**

관리자 권한이 **특정 계정 하나에 묶여** 있습니다. 카카오로 들어오시면
**다른 계정**이 생기고 그 계정은 일반 회원입니다. 이메일 칸을 먼저
없애시면 **`/admin` 에 영영 못 들어가십니다.**

차례는 그 글에 적어 두었습니다 — ① 소셜로 먼저 들어가고 ② 그 계정 번호를
찾아 ③ SQL 한 줄로 관리자로 올리고 ④ `/admin` 이 열리는지 보고 ⑤ **그
다음에야** 이메일 칸을 뺍니다.

## 지금 사이트 쪽 상태

| | |
|---|---|
| 카카오 단추 | **있습니다.** Supabase 가 「켜졌다」고 답하면 섭니다 |
| 우리가 보내는 주소 | `?provider=kakao&redirect_to=...` — 동의항목을 **안 싣습니다** |
| 돌아올 자리 | 매직링크와 **같은 함수**를 씁니다 |
| 이메일 매직링크 | **그대로** 돕니다 (한 줄도 안 건드렸습니다) |
| 새 가입자의 권한 | **일반 회원** 고정 (관리자로 올리는 길이 코드에 0개입니다) |

⚠️ 다만 **운영에 Supabase 환경변수가 없으면** 로그인 화면이 「준비 중」
셋으로만 보입니다. 그 둘(`SUPABASE_URL` · `SUPABASE_ANON_KEY`)이
Vercel 에 들어가 있고 **다시 배포**되었는지부터 확인하세요 —
`https://storeway.co.kr/api/session` 을 열어 `"auth":true` 면 켜진 것이고,
`"auth":false` 면 **비어 있는 변수 이름을 그 자리에서 말해 줍니다.**
