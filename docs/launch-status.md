## 2. 누락 — 비어 있어서 그 기능이 **안 되거나 줄째 빠지는** 것

| 항목 | 지금 | 비어 있으면 | 하실 일 |
|---|---|---|---|
| 사업자 정보 아홉 칸 (`js/data/site.js`) | 전부 비어 있음 | SITE_LIVE 를 켜면 빌드가 멈춤 · 화면에서 그 줄이 빠짐 | 상호 · 대표자 · 사업자등록번호 · 통신판매업 신고번호 · 주소 · 전화 · 이메일 · 개인정보 보호책임자 · 시행일 |
| **운영자(관리자 · 직원) 계정** | **0명** (계정 2개 모두 손님) | `/admin` 이 안 열림 → 업체 승인 · 요청 배정 · 비교견적 배정을 아무도 못 함 | Supabase → Authentication 에서 사장님 UID 확인 → SQL 편집기에서 그 계정만 `admin` 으로 (DB 변경이라 별도 승인) |
| 사진 저장소 (Storage 버킷) | **0개** | 손님 사진 · 업체 증빙 · 시설 사진 · 매물 사진 · 글 사진 · 광고 소재 칸이 전부 안 나옴 | 비공개 버킷(손님 사진 · 증빙) + 공개 버킷(시설 · 매물 · 글 · 광고) 만들기 |
| `SUPABASE_SERVICE_KEY` · `INTAKE_BUCKET` · `PROVIDER_BUCKET` (Vercel) | 없음 (운영 `/api/upload` 의 `up:false`) | 버킷을 만들어도 사진 칸이 안 나옴 | Vercel 환경변수 셋 → 다시 배포 |
| 상담 가능 시간 · 보호책임자 이메일 · 전화 | 비어 있음 | 고객센터 · 방침에서 그 줄만 빠짐 | `site.js` |
| 네이버 · 구글 확인 문자열 | 비어 있음 | 검색엔진 등록 불가 (SITE_LIVE 전에는 필요 없음) | `site.js` |

## 3. 미확인 — 이 세션에서 볼 수 없는 것

| 항목 | 까닭 | 사장님 확인 방법 |
|---|---|---|
| 카카오 로그인 실제 성공 · 로그아웃 | 이 세션은 Supabase 로 나가는 브라우저 연결이 막혀 있음 | 운영에서 카카오 로그인 → `/my` → 맨 위 「로그아웃」 |
| 메인 장터 · 조인 · 질문 칸의 실제 화면 | 같은 까닭 (DB 읽기로는 칸 · 권한 정상 · 각 0건) | 메인에서 그 세 칸이 「아직 … 없습니다」 + 올리는 길로 보이는지 |
| 휴대폰 본인확인(PASS) · 문자 인증(SMS OTP) | **둘 다 저장소에 없습니다** — 서로 다른 기능입니다 | PASS 는 본인확인기관 계약 · 서버 연동이 필요, SMS OTP 는 Supabase 휴대폰 로그인 + 문자 발송사 계약이 필요 (방침의 수탁자도 같은 날) |

## 5. 업체 신청 → 승인 → 작업실 → 자료 등록 (지금 도는 절차)

1. 업체가 `/join` 에서 입점 신청 (로그인했으면 신청에 계정이 담김 · 0071)
2. 운영자가 `/admin` → 「입점 신청」에서 확인 → 「이 신청으로 업체 만들기」
3. 승인(`approve_provider`) → 로그인 신청이면 「신청하신 분을 담당자로 잇기」, 아니면 초대 코드 발급 → 업체가 `/desk` 에서 입력
4. 업체가 `/desk` 에서 영업 지역 · 가격 · 사진 · 배정 연락처를 채움 (맨 위 「먼저 하실 것」이 안내)
5. 운영자가 `/admin` 에서 「배정 가능」을 켬 → `node tools/pull-providers.js` 로 자료를 가져와 다시 배포해야 손님 화면에 보임

⚠️ 지금은 **운영자 계정이 0명이라 2단계부터 막힙니다** (2절).
