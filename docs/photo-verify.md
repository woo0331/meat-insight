## 2. 무엇을 어디서 눌러 봤나

| 걸음 | 어디서 | 어떻게 |
|---|---|---|
| **올리기** | `test-desk` | `/api/upload` 에 **POST → 서명된 주소로 PUT** 이 실제로 가는지를 **보낸 꾸러미를 뜯어** 봅니다 |
| **EXIF 떼기** | `test-desk` | 참 PNG 를 고르면 보내는 종류가 **`image/jpeg`** 로 바뀌는지(= canvas 를 지났다 = 위치정보가 사라졌다) · 이름만 `.jpg` 인 파일은 **고르는 자리에서** 거절되고 PUT 이 **한 번도 안 가는지** |
| **저장** | `tools/sql/*.js` | 문이 경로를 **직접 짓는지** · 남의 칸에 못 쓰는지 · 장수 한도 · 표에 **바로 못 넣는지** |
| **상세 조회** | `tools/sql/*.js` | 공개 보기가 **무엇을 내고 무엇을 안 내는지**(증빙서류 · 심사 전 사진) |
| **수정(차례)** | `tools/sql/listing.js` · `trip.js` | 늘어놓은 배열을 **통째로 · 빠짐없이** 받는지 · 일부만 보내면 거절하는지 |
| **삭제** | `tools/sql/*.js` | 보이는 사진은 **지우지 않고 빼는 중**으로 · 심사 전 사진은 **줄째** · 두 번 빼면 거절 |
| **권한** | `tools/sql/*.js` | 올린 분 · **남의 업체** · 손님 · 비로그인을 **갈라서** · 거절하는 **말까지** |

## 3. 재심사 중 사진이 공개본을 바꾸는가 (지시서가 콕 집은 자리)

`tools/sql/trip.js` 에 **13건**을 새로 넣고 눌렀습니다 — 전부 통과.

| 묻는 것 | 결과 |
|---|---|
| 승인된 상품에 새로 올린 사진이 **심사 전**인가 (`live = false`) | ✅ |
| **공개 목록이 안 바뀌는가** (심사도 안 거친 그림이 안 나갑니다) | ✅ |
| **카드의 사진 수도 안 바뀌는가** (기존 승인본이 안 사라집니다) | ✅ |
| 올린 여행사는 제 **심사 중 사진의 id 를 읽는가** | ✅ |
| **남의 여행사에게는 안 보이고 못 빼는가** | ✅ |
| 손님 · 비로그인이 못 빼는가 | ✅ |
| 심사 전 사진은 빼면 **줄째 사라지는가** | ✅ |
| 빼고 나서도 **공개 목록이 그대로**인가 | ✅ |
| **승인을 거치면** 그때 공개 목록에 들어오는가 | ✅ |

⚠️ 마지막 걸음에서 **제 검사가 먼저 틀렸습니다** — `move_trip` 은
**같은 상태로 못 옮깁니다**("이미 그 상태입니다"). 이미 승인된 상품에
그냥 승인을 부르면 거절당하고 **아무 일도 안 일어납니다.** 판매 중지 →
다시 판매로 심사 중으로 내린 뒤 승인하도록 고쳤습니다.

## 4. ⚠️ 못 해 본 것 — **여기가 미검증입니다**

1. **실제 Supabase Storage 에 바이트가 올라가는 것.** 서명된 올릴
   주소를 내주려면 `SUPABASE_SERVICE_KEY` 와 버킷 둘
   (`INTAKE_BUCKET` · `PROVIDER_BUCKET`)이 있어야 합니다 — 지금
   운영에 **셋 다 없습니다**. 그래서 `api/upload.js` 는 「아직 열지
   않았습니다」를 돌려주고, 화면은 사진 칸을 **아예 안 그립니다**.
2. **공개 URL 로 그 파일이 실제로 열리는 것.** 1 이 안 되면 잴 수가
   없습니다.
3. **올라간 사진이 빌드된 `/pro` 화면에 박히는 것.**
   `tools/pull-providers.js` 가 가져와야 하는데, 그 도구도 운영
   Supabase 로 나가야 합니다(이 세션은 밖으로 못 나갑니다).

👉 위 셋은 **버킷 둘과 service key 를 넣으신 뒤**에야 잴 수 있습니다.
`node tools/check-open.js` 가 그 셋을 세어 줍니다.

⚠️⚠️ **그때까지는 「사진 기능이 운영에서 된다」고 적지 않습니다.**
지금 말할 수 있는 것은 **「코드와 DB 는 끝까지 눌러 봤고, 저장소
밖의 설정이 없어 운영에서는 못 눌러 봤다」** 까지입니다.
