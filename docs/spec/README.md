# 확정 시안 — 파일과 대상 화면

대표님이 주신 **카테고리 확정 시안**을 그대로 담아 둡니다.
⚠️⚠️⚠️ **대화는 길어지면 앞이 요약으로 접히고 첨부 이미지는 요약에 남지
않습니다.** 그래서 다음 차수가 「시안이 어디 있나」를 찾지 않도록 여기
둡니다 — 2026-11-12 에 그 자리를 글로만 적어 두었다가, 세션이 끝나면
파일이 사라지는 자리였습니다.

⚠️ **이 저장소는 공개입니다.** 넣기 전에 다섯 장을 확대해서 보았고
매출 · 개인정보 · 사업 계획이 보이는 자리는 없었습니다 — 전부 머리에
「디자인 시안 · 예시 데이터」 라벨이 붙은 화면 그림이고 안의 업체 ·
금액 · 상품은 모두 「예시」입니다. **새 시안을 넣으실 때도 그 확인을
먼저 하세요.**

## 아직 안 온 다섯 — 오면 여기에 같은 이름 규칙으로

| 받을 이름 | 시안 번호 | 대상 주소 |
|---|---|---|
| `01-booking.webp` | ① 골프장 부킹 | `/cat/booking` |
| `02-matchup.webp` | ② 골프 조인 | `/cat/matchup` |
| `03-used.webp` | ③ 중고 골프장터 | `/cat/used` |
| `04-lesson.webp` | ④ 골프 레슨 | `/cat/lesson` |
| `06-market.webp` | ⑥ 골프용품 마켓 | `/cat/market` |

⚠️ **이름은 `AM_CATS` 의 키**(`js/data/catalog.js`)를 씁니다 — 번호만
쓰면 분류 차례가 바뀌는 날 어느 화면인지 알 수 없게 됩니다.

## 한 장에 PC 와 모바일이 같이 있습니다

다섯 장 모두 **왼쪽이 PC · 오른쪽이 모바일**입니다(연습장 · 피팅은
아래에 「PC (데스크톱)」 · 「모바일」 꼬리표가 붙어 있습니다).
그래서 **구현 캡처도 둘을 같이** 찍습니다 — `tools/shot.js` 가 빌드가
찍는 화면을, `tools/shot-desk.js` 가 설정이 있어야 열리는 화면을
PC 1280 · 폰 360 두 폭으로 찍습니다.

## 다섯 장이 **같이** 요구하는 것 — 폰 바닥 탭

⚠️⚠️ 연습장 · 피팅 · 여행 · 인력 · 커뮤니티 **다섯 장 전부**의 모바일
쪽에 바닥 탭이 있고, 칸이 **넷으로 같습니다** — 홈 · 검색 · 등록 ·
내정보. 「채팅」은 **어느 시안에도 없습니다**(그래서 안 만듭니다).
한 화면의 장식이 아니라 **사이트 전체의 구조**라, 분류마다 따로 만들지
않고 한 곳에서 그립니다.
