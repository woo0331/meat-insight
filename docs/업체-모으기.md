# 첫 업체 10곳 모으기 — 운영자용

사이트의 진짜 병목은 디자인이 아닙니다. **등록된 업체가 0곳**인 것입니다.
요청을 올려도 견적 보낼 사람이 없으면 요청자는 다시 안 옵니다.

그런데 도축장·가공업체 사장님께 "사이트 가서 가입하세요" 하면 열에 아홉은
안 합니다. 그래서 **운영자가 대신 넣고 초대 문자를 보내는 길**을 만들었습니다.

---

## 한 번만 하는 준비

Supabase → SQL Editor 에서 순서대로:

1. `db/phase8_notify.sql` — 알림 큐
2. `db/phase9_invite.sql` — 초대·연결

⚠️ 8번을 먼저 실행해야 9번이 돕니다.

---

## 사장님 한 분을 넣는 순서

### 1. 명함을 받아 옵니다

전화로 영업하든 찾아가든, 필요한 건 **상호 · 연락처 · 지역 · 분야** 넷입니다.
나머지(대표자·주소·품목·소개)는 있으면 넣고 없으면 비워 둡니다.

### 2. 관리자 화면에서 넣습니다

`admin.html` → **업체** 탭 → **+ 업체 추가**

- 연락처는 **요청 알림이 갈 번호**입니다. 잘못 적으면 알림이 영영 안 갑니다.
  형식이 이상하면 등록 단계에서 막습니다.
- 분야는 여러 개 고를 수 있습니다. 고른 분야의 요청만 알림이 갑니다.

### 3. 초대 문자를 보냅니다

목록에서 그 업체의 **초대 문자** 버튼 → 문구가 통째로 복사됩니다.

```
○○축산 사장님, 고리(aboutmeat.co.kr)에 업체를 등록해 두었습니다.
아래 링크로 들어오시면 견적 요청을 직접 받아보실 수 있습니다.
https://aboutmeat.co.kr/#/claim/xxxxxxxx
```

붙여넣어 보내시면 됩니다.

---

## 사장님이 안 눌러도 됩니다

여기가 핵심입니다. **초대 링크를 안 눌러도 요청 알림은 갑니다.**

조건에 맞는 요청이 올라오면 등록해 둔 번호로 문자(나중엔 알림톡)가 갑니다.
`db/phase9_invite.sql` 의 `trg_gori_notify_guest` 가 계정 없는 업체를 맡습니다.

링크를 누르는 건 **직접 관리하고 싶어질 때**입니다 —
견적을 보내거나, 업체 정보를 고치거나, 사진을 올릴 때.

그래서 순서가 이렇게 됩니다:

1. 운영자가 넣는다 → 사장님은 아무것도 안 해도 됨
2. 요청이 오면 문자가 간다 → "어, 진짜 오네"
3. 그때 링크를 눌러 계정을 만든다 → 직접 관리 시작

"가입부터 하세요" 보다 훨씬 잘 넘어갑니다.

## 목록에서 보이는 것

| 표시 | 뜻 |
|---|---|
| **계정 없음** | 운영자가 대신 넣음. 문자로만 알림이 감. 초대 문자를 보낼 수 있음 |
| **계정 연결됨** | 사장님이 링크를 눌러 가져감. 직접 관리 중 |
| 대신 등록 · (이메일) | 누가 넣었는지 |

## 주의

- **초대 링크는 한 번만 씁니다.** 사장님이 누르는 순간 열쇠가 지워집니다.
  남이 그 링크를 주워도 못 씁니다.
- **열쇠 없이는 못 가져갑니다.** 연결은 DB 함수(`gori_claim_supplier`)가
  하고, 열쇠가 맞고 아직 주인이 없을 때만 그 한 줄을 바꿉니다.
  브라우저에서 업체를 직접 고치게 두면 anon 키로 아무 업체나 가져갈 수
  있어서 그렇게 만들지 않았습니다.
- **연락처를 지어내지 마세요.** 번호가 없으면 알림은 `skipped` 로 남고
  보낸 척하지 않습니다.

`test/claim-e2e.js` · `test/rls-test.sh` 가 전부 감시합니다.
