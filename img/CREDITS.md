# 사진의 출처와 사용 권리

⚠️⚠️⚠️ **생성형으로 만들었다고 해서 사용 권리가 자동으로 보장되지
않습니다.** 도구마다 약관이 다르고, 같은 도구라도 요금제에 따라
상업적 이용이 갈립니다. 그리고 약관은 **바뀝니다** — 그때 "언제 ·
무엇으로 만들었는지" 가 없으면 따져 볼 수조차 없습니다.

⚠️ 그래서 사진을 넣으시는 날 **여기에 같이 적습니다.** 사진만 넣고
이 줄을 안 적으면, 몇 달 뒤에 아무도 모릅니다.

---

## 적는 법

사진 묶음 하나마다 아래 일곱 줄입니다. **빈 줄을 남기지 마세요** —
모르는 것은 "모름" 이라고 적는 편이 빈칸보다 낫습니다 (빈칸은 "아직
안 적었다" 와 "확인했는데 없다" 를 구별 못 합니다).

```
무엇          어느 자리의 사진인지 (보기: 분류 카드 10장)
파일          img/ 안의 경로
만든 것       도구 이름과 판 (보기: ChatGPT / GPT-4o 이미지)
만든 날       YYYY-MM-DD
받은 날       YYYY-MM-DD
권리 근거     약관의 어느 줄인지 · 확인한 날 · 링크
사람이 본 것  상표 · 글자 검수를 누가 언제 했는지, 무엇을 고쳤는지
```

## 기록

### 분류 카드 10장 — `img/mock/cat-*.jpg` (지금 쓰는 것)

```
무엇          분류 카드 10장 (메인 화면)
파일          img/mock/cat-lesson.jpg … cat-community.jpg
만든 것       (적어 주세요 — 지피티로 만드셨다면 도구 이름과 판)
만든 날       2026-11-04 무렵 (받은 날 기준 · 정확한 날짜는 적어 주세요)
받은 날       2026-11-04
권리 근거     ⚠️ 아직 확인 안 했습니다 — 영업 시작 전에 적어야 합니다
사람이 본 것  2026-11-04 · 원본 100% 로 열 장 전부 확인
              ⚠️ 상표 둘을 찾아 지웠습니다:
                 cat-lesson  모자 앞판의 Titleist
                 cat-market  흰 골프백의 같은 글씨 · 검은 백의 표식
              남긴 것 (읽히지 않는 AI 문양이라 지우지 않음):
                 cat-range      시뮬레이터 화면의 숫자 · 글자
                 cat-career     가슴의 방패 문양
                 cat-community  모자 셋의 표식
```

⚠️⚠️ **이 묶음은 임시입니다.** 콜라주에서 오려낸 290px 를 늘린 것이라
2400×1350 개별 원본으로 다시 받기로 했습니다. 새 것이 오면 위 칸을
**덮어쓰지 말고 아래에 새로 적고**, 이 줄은 "바꿨습니다" 로 남기세요
— 지운 기록은 다툴 때 쓸 수 없습니다.

### 히어로 · 묶음 카드 · 띠 — `img/hero.jpg` · `img/zone-*.jpg` · `img/mock/*-banner.jpg`

```
무엇          메인 큰 사진 1 · 묶음 카드 4 · 띠 2
만든 것       (적어 주세요)
만든 날       (적어 주세요)
권리 근거     ⚠️ 아직 확인 안 했습니다
사람이 본 것  ⚠️ match-banner.jpg — 골프공에 방패 로고가 박혀 있습니다
              (사진 안에 있어 나중에 못 바꿉니다)
```

## 새 사진을 받으시는 날 — 사람이 해야 하는 것

도구(`tools/take-cat-photos.js`)가 재는 것은 여기까지입니다 —
**크기 · 비율 · 또렷함 · 밝기 · 색 치우침 · 열 장의 고른 정도.**

아래 셋은 **기계가 영원히 못 봅니다.**

1. **상표 · 글자** — 원본을 100% 로 열어서 보세요.
   ⚠️ 모자 앞판 · 상의 가슴 · 골프백 · 클럽 헤드 · 진열대 · 노트북 ·
   실내 스크린. 카드 크기(108~166px)에서는 안 읽히지만 **원본은
   저장소에 그대로 들어갑니다.**
   ⚠️ 2026-11-04 에 "no logo" 로 만들었다는 열 장 가운데 **둘**에서
   실제 브랜드명이 나왔습니다. 그림 만드는 기계는 그 말을 못 지킵니다.
2. **골프로 읽히는가 · 얼굴 · 손 · 장비 모양이 자연스러운가.**
3. **상업적 이용 권리** — 위 칸을 채우세요.
