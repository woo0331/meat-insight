실제 거래 사례
AboutMeat를 통해 성사된 실제 매칭 사례
CASE 01 · 고기 구매
강남 한우 전문점 — 한우 등심 100kg 납품 업체 찾기
5개 업체 견적 수령, 품질·납기·단가 비교 후 최적 업체 선정. 기존 단가 대비 납품 비용 8% 절감, 주 2회 정기계약 체결.
▲ 납품단가 8% 절감 · 주 2회 정기계약
CASE 02 · 구인구직
안양 정육점 — 정육사 경력직 3년 이상 채용
요청 등록 후 3일 내 12명 지원, 경력·자격증·전공 비교 후 면접 연결. 기존 구인 광고 대비 채용 비용 70% 절감.
▲ 3일 만에 면접 연결 · 채용 비용 70% 절감
CASE 03 · 인테리어
수원 예비창업자 — 고깃집 인테리어 35평 견적
4개 인테리어 업체 견적 비교. 최저가 대비 시공 품질·AS 조건 종합 고려, 최적 업체 선정. 예산 대비 450만원 절감.
▲ 4개 업체 비교 · 450만원 절감
CASE 04 · 육가공 의뢰
육포 식품 브랜드 — OEM 생산 가능 업체 매칭
HACCP 인증 업체 조건 포함 요청서 등록, 3개 업체 견적·샘플 제안. 최적 업체 선정 후 샘플 생산 진행 중.
▲ HACCP 인증 OEM 업체 3개 매칭
WHY ABOUTMEAT
기존 방식의 문제를 해결합니다
PROBLEM 01
업체마다 직접 전화해야 한다
SOLUTION
요청서 하나로 전국 관련 업체의 견적이 자동으로 도착합니다
PROBLEM 02
신뢰할 수 있는 업체인지 모른다
SOLUTION
사업자 인증, 리뷰, 거래이력, 클레임률까지 투명하게 공개됩니다
PROBLEM 03
고기 업계 정보가 흩어져 있다
SOLUTION
구매·인력·장비·물류·창업 모든 분야를 한 곳에서 연결합니다
PROBLEM 04
견적 비교가 어렵다
SOLUTION
가격, 납기, 조건, 리뷰를 한 화면에서 비교하고 선택합니다
PROBLEM 05
좋은 직원 찾기가 너무 힘들다
SOLUTION
정육사, 발골사, 세절기사 등 업계 전문인력을 직접 매칭합니다
PROBLEM 06
창업 정보를 어디서 얻어야 할지 모른다
SOLUTION
상권분석, 원가계산, 인테리어까지 52년 업력의 전문가가 연결됩니다

AboutMeat 신뢰 시스템
엔카처럼 인증, 숨고처럼 리뷰, 아정당처럼 비교
✅
사업자 인증
사업자등록증, 관련 허가증, 업종 확인을 완료한 업체만 AboutMeat 인증 배지를 발급합니다.
⭐
거래 기반 리뷰
실제 거래 후에만 리뷰 작성이 가능합니다. 품질, 수율, 납기, 응답속도를 각각 평가합니다.
📊
투명한 지표
거래 건수, 응답속도, 클레임률, 재구매율을 모두 공개합니다. 숨기는 것이 없습니다.
🏆
업체 등급제
거래 이력, 리뷰 점수, 응답속도, 클레임률에 따라 일반·우수·인증 등급을 부여합니다.
🛡
관리자 중재
거래 분쟁 발생 시 AboutMeat 관리자가 중재합니다. 구매자와 공급자 모두를 보호합니다.
⚡
응답속도 추적
견적 요청 후 업체의 응답 시간을 자동으로 측정합니다. 느린 업체는 순위에서 하락합니다.
