# 시연 환경 (`tools/demo/`)

아버님께 보여 드리는 **시연용 화면**입니다. 운영과 완전히 떨어져 있습니다.

## 켜는 법

```
node tools/demo.js            # 기본 4180 번
node tools/demo.js 5000       # 포트를 고르실 수 있습니다
```

켜지면 주소가 찍힙니다. **이 기계 안에서만 열립니다** — 밖에서는
접속할 수 없습니다.

## 한 번에 지우는 법

```
rm -rf tools/demo tools/demo.js
```

끝입니다. 화면 코드 · 마이그레이션 · 검사에 섞인 줄이 **한 줄도**
없습니다. (`0081_course_photo.sql` 은 시연용이 아니라 **제품 코드**라
남습니다 — 확정 시안 ① 의 골프장 사진 자리입니다.)

## 운영과 무엇이 다른가

| | 운영 | 시연 |
|---|---|---|
| 자료 | Supabase | `tools/demo/rows.js` (**메모리에만**) |
| 업체 · 프로 | `pull-providers.js` 가 DB 에서 | `tools/demo/data.js` |
| 사진 | 공개 버킷 | 저장소의 분류 사진(`img/mock/`)을 잘라 만든 것 |
| 로그인 | 메일 · 소셜 | **안 켭니다** (손님 눈으로만 봅니다) |
| 예약 · 문의 · 신청 | 접수됩니다 | **403 으로 막힙니다** |
| 알림 | 내부 알림이 쌓입니다 | 한 건도 안 쌓입니다 |

## 안전 장치

* 모든 화면 맨 위에 **「시연용 · 예시 데이터」** 띠가 붙습니다
  (`tools/demo/server.js` 가 HTML 에 끼웁니다 — 저장소의 화면 파일은
  한 글자도 안 고칩니다).
* 상호 · 프로 성함 · 매물 제목이 전부 **「(예시)」**로 시작합니다.
* **전화번호를 한 글자도 안 넣습니다** — 지어낸 번호를 적으면 엉뚱한
  분께 전화가 갑니다.
* 저장소를 **`tar` 로 복사**해서 거기에만 씨앗을 심고 빌드합니다 —
  작업 폴더 · HEAD · 가지가 그대로입니다(2026-11-09 사고를 막는 자리).
* `tools/demo/check.js` 가 켜질 때마다 **예시 자료가 DB 가 받는 값인지**
  맞춰 봅니다 — 키 · 지역 · 상태 · 사진 경로 꼴 · 「(예시)」 · 전화번호.
  하나라도 어긋나면 **서버가 안 켜집니다**.

## 밖에서 열리게 하려면 — **사장님이 고르실 일** (2026-11-13)

시연 서버는 **`127.0.0.1` 에서만** 열립니다. 이 세션은 밖으로 못 나가고
(프록시가 CONNECT 에 403), 터널 · 호스팅은 **가입이나 승인**이 필요해서
**준비만** 했습니다. 고르실 수 있는 것은 셋입니다.

| 길 | 비용 · 승인 | 보이는 것 | 위험 |
|---|---|---|---|
| **① 사장님 기계에서 직접 켜기** (권합니다) | 없음 | **전부** — 열 분류 · 목록 → 상세 · 거르개 · 탭 | 없음. 그 기계에서만 보입니다 |
| ② Vercel 에 **별도 시연 프로젝트** | 사장님이 Vercel 에서 새 프로젝트를 만드셔야 합니다 | 전부. 다만 시연 서버를 `api/` 서버리스로 옮겨야 합니다 | ⚠️⚠️ **시연 코드가 저장소에 영구히 남습니다** — 운영 배포에 섞일 길이 생깁니다. 지금은 `tools/` 안에만 있어서 `rm -rf` 한 번으로 지워집니다 |
| ③ **정적만** 올리기 | 사장님이 새 프로젝트를 만드셔야 합니다 | **반쪽** — 빌드가 찍는 화면(골프장 정보 탭 · 업체 카드 · 레슨 · 연습장 · 피팅)만. 티타임 · 중고 · 게시판 · 여행 목록은 **안 나옵니다**(DB 를 부릅니다) | ⚠️ 보시는 분이 **"안 만들었구나"** 로 읽습니다 |

### ① 사장님 기계에서 켜는 법

```bash
git clone <이 저장소>        # 또는 이미 받아 두신 폴더에서
cd meat-insight
git checkout claude/git-branch-workflow-j74dol
node tools/demo.js 4180
# → 브라우저에서 http://127.0.0.1:4180
```

끄실 때는 그 창에서 Ctrl+C. 지우실 때는 —

```bash
rm -rf tools/demo tools/demo.js
```

⚠️ 필요한 것은 **Node 22 이상**뿐입니다. 사진을 자르는 데 ImageMagick 을
쓰지만, 없으면 원본을 그대로 쓰고 **그 사실을 적어 줍니다**.

⚠️⚠️ **②를 고르시면 말씀해 주세요** — 시연 서버를 `api/` 로 옮기는 일은
저장소 구조를 바꾸는 것이라 지금 혼자 결정하지 않았습니다.
